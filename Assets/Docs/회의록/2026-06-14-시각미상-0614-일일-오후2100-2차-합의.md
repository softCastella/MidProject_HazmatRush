## 세션 오후 17:00 — 타이머 경고 SFX · GameScene 카운트다운

### 합의 — 잔여 시간 경고 SFX (`Timer`)

| 항목 | 규칙 |
|------|------|
| **재생 조건** | HUD 표시 초(`CeilToInt`) ≤ `warningSfxStartSeconds`(기본 **16**) · ≥ 1 |
| **재생 방식** | **1회** `Play()` — `countdownSFX.ogg` (10→0 한 파일) |
| **일시정지** | 오염 경고 → `PauseCountdown()` · SFX **Pause** (Stop·재시작 금지) |
| **재개** | 오염원 등장 후 `ResumeCountdown()` · SFX **UnPause** |
| **정지** | 0초 · `StopCountdown()` · 게임오버 · 패널티 · 임계값 초과(회복) |
| **숫자 색** | `warningSfxStartSeconds` 이하 **빨간색** · **0초 포함** |

### 합의 — 카운트다운 시작

| 씬 | 규칙 |
|----|------|
| **GameScene** | `StageManager.LoadStage` → `SetStartTime` + `StartCountdown()` |
| **Timer** | `[DefaultExecutionOrder(100)]` · `Start()`에서 `isRunning = false` **금지** |

## 세션 오후 21:00 — UI 스케일 · 저장 · 스플래시 · 사망 SFX · 빌드

### 배경

- 빌드 **1280×720** (16:9) 기준 QA 중, 창 **자유 리사이즈** 시 HUD·월드 배경 스케일 불일치.
- 타이틀 **이어하기**가 Documents 저장 때문에 빌드 첫 실행에도 표시됨.
- 스플래시 카메라 **흰색** → UI 수정 후 **검정+로고 박스**로 보임.

### 합의 — UI·카메라 스케일 (1280×720 · 16:9)

| 항목 | 규칙 |
|------|------|
| **빌드 해상도** | Player Settings **1280×720** · Windowed |
| **Canvas** | `Match Width` 유지 · 세로가 긴 화면은 `referenceResolution` **높이만 동적 확장** (`CanvasBackgroundCover`) |
| **월드 배경** | `CameraAspectFit` — **contain**(줄어듦) · cover(잘림) **금지** |
| **Inventory** | 우측 하단 **앵커** (좁은 화면 클립 방지) |
| **카메라 배경색** | `CanvasBackgroundCover`에서 **강제 검정 금지** — 씬 Inspector 값 유지 (스플래시 흰색) |

### 합의 — 창 리사이즈 (후속)

| 항목 | 결정 |
|------|------|
| **자유 리사이즈** | 0612 합의 `resizableWindow: 1` 유지 · 비 16:9에서 레이아웃 깨짐 **알려진 한계** |
| **권장** | 발표·데mo는 **1280×720 고정** · `Resizable Window` 끄기 검토 |
| **프리셋** | 1920 / 1600 / 1280 (각 16:9) — **타이틀 옵션은 백로그** |

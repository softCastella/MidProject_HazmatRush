## 세션 오후 12:27 — 경고·맵·클리어·회복

### 배경

- 실플레이 UX: 경고 중 월드 진행, 맵 잔존 회복·맵 전환 타이밍, 클리어 시 맵 아이템 잔존.

### 경고 구간 (`WarningAndSpawn`)

| 멈춤 | 계속 |
|------|------|
| `canMove`, 타이머, 배경 스크롤 | BGM (dim 없음) |

| | **`Time.timeScale = 1` 유지** |

- 해제: 오염원 등장·페이드인 시작 후.

### 맵 잔존 회복 + 구간 전환

- 착지(`IsLandedOnMap`) 1개 이상 → 배경 스크롤 정지 (경고·오염원 활성과 OR).
- 구간 중화 후 **즉시 페이드 금지** → `"오른쪽으로 이동하세요"` → `mapEndX` 도달 시 페이드.
- 잔존 아이템은 맵 이동을 막지 않음. 전환 시 `ClearMapRecoveryItems()`. 전환 후 `ResetRange`, `segmentMovementUnlocked = false`.

### 스테이지 클리어

- `ShowClear` 직전 맵 아이템 **인벤 자동 획득** (`AutoCollectMapRecoveryItems`).
- Clear 애니 2초 후 `anim.speed = 0` → 패널 ([Bug 2026-06-05](../Bug/2026-06-05-시각미상-클리어-가이드-중화VFX-fixes.md) 유지).

### 금지

- 경고 `timeScale = 0` 재도입 · 중화 직후 자동 맵 전환 · 클리어 시 `ResetToDefault()`.

## 세션 오후 17:00 — 방호복 HUD(우측 상단) · 오염원 HP바 · 접촉

### 배경

- 플레이어 방호복 HP를 **화면 우측 상단 고정 HUD**로 표시.
- 계단형 스프라이트는 Slider fill이 아니라 **프레임별 Image**로 단계 전환.
- 오염원 HP 슬라이더는 **월드 추적 1개** · 방호복 바와 **분리**.

### Hierarchy (GameScene `HUD_Canvas`)

```text
HpBar                          ← Anchor: 우측 상단 (1,1), Pivot (1,1)
├── Protection                 ← 방호복 블록
│   ├── ProtectionLabel        ← "방호복 내구도" 등 라벨
│   └── protectionHp           ← ProtectionHpBarUI
│       ├── Bg                 ← Image (테두리/배경, 스프라이트 5_7)
│       ├── FillArea           ← RectTransform + Mask (Image 아님)
│       │   ├── Fill_0         ← 100% (7칸)
│       │   ├── Fill_1 … Fill_5
│       │   └── Fill_6         ← 1칸
│       └── Text (TMP)         ← 바 안 "000%" (D3 + %)
├── Timer                      ← 남은 시간 (방호복 아래)
└── pollutantHpSlider          ← HUD_Canvas 직속 (HpBar 밖)
    └── WorldSpaceUIFollower   ← worldTarget: None (접촉 시 코드 할당)
```

> 예전 이름 `protectionHpSlider`는 **`protectionHp`** 로 통일. 별도 `ProtectionNum` 텍스트는 **삭제** — 퍼센트는 바 내부 TMP만 사용.

### 방호복 바 동작 (`ProtectionHpBarUI`)

| HP | Fill 표시 | 텍스트 |
|----|-----------|--------|
| 100% | `Fill_0`만 ON | `100%` |
| 중간 | `Fill_1` … `Fill_5` 중 하나 | `085%` 등 `D3%` |
| 최저(1칸) | `Fill_6` | `001%` 등 |
| **0** | **전부 OFF** (빈 바) | `000%` |

- `Player.UpdateProtectionBar()` → `protectionHpBar.SetProtection(curProtection, maxProtection)`.
- 접촉 여부와 **무관하게 항상 표시** (우측 상단 HUD).

### 오염원 HP 슬라이더 (`pollutantHpSlider`)

| 항목 | 규칙 |
|------|------|
| 개수 | 씬 **1개** — `PollutantManager.pollutantSlider`가 모든 오염원에 주입 |
| 표시 | **접촉 중만** `SetActive(true)` |
| 추적 | `ShowContactBars`에서 `worldTarget` = 접촉 중인 그 오염원 `SpriteRenderer`(없으면 `transform`) |
| Inspector | `worldTarget` **비움** — 특정 오염원에 수동 연결 금지 |
| 부모 | **`HpBar` 자식 금지** — `HUD_Canvas` 직속 |

### 접촉 (A~C/D 동일 — [§4](../회의록/2026-06-05-시각미상-플레이어-오염원-로직-검토.md) 재확인)

```text
OnTriggerEnter2D  → BeginPlayerContact (HP바, AddPollutantTouch)
OnTriggerStay2D   → currentPlayer 갱신만 (데미지 없음)
FixedUpdate       → playerInTrigger && IsPlayerInContact() → ApplyPlayerContactDamage
OnTriggerExit2D   → bounds padding 0 겹치면 무시, 아니면 EndPlayerContact
EndPlayerContact  → HP 초기화, RemovePollutantTouch, VFX/SFX off, 슬라이더 숨김
```

**`IsPlayerInContact`:** 콜라이더 bounds 교차. 가스(D) + `IsValveAnimActive`일 때만 padding `0.15f`.

**금지:** `LateUpdate` bounds로 접촉 시작·데미지 · 넓은 `GetContactOverlapPadding`으로 Exit 무시 · `IsPlayerContactActive`가 플래그만 보기.

### 중화 VFX (기존 유지)

- A~C + 접촉 + 정답 아이템만 `RefreshNeutralizationVfx` ON.
- D(가스)는 CFXR 중화 VFX 없음 · 밸브 애니·SFX만.

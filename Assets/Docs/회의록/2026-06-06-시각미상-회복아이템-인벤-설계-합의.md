## 1. 배경

- 맵 회복 아이템(방호복 회복 / 시간 연장) 프리팹·스폰 구조는 일부 연결됨.
- 인벤은 **고정 4칸 bool** 구현 상태 — 스택·JSON·Scroll View·빈 슬롯 UI 미완.
- `InventoryContainer`에 **중화 아이템(`ItemManager` Z/X)** 과 회복 인벤이 **같은 4슬롯**을 공유 중 → 분리 필요.

---

## 2. 프리팹·에셋 네이밍 (합의)

| 용도 | 경로·이름 |
|------|-----------|
| 맵 픽업 | `Assets/Prefabs/Item/mapProtectRecovPrefab`, `mapTimeRecovPrefab` |
| 인벤 칸 UI | `Assets/Prefabs/InvenItem/invProtectRecovPrefab`, `invTimeRecovPrefab` |
| 빈 칸 (1단계 예정) | `Assets/Prefabs/InvenItem/invEmptySlotPrefab` |

- 맵 = 월드 스프라이트 + `RecoveryItem` + Trigger 콜라이더.
- 인벤 = Image + 이름(TMP) + Count 등 — **Instantiate** 대상.

---

## 3. JSON 정의 (`recovery_items.json`)

- **정의만** 저장. 런타임 `count`는 JSON에 넣지 않음.

```json
[
  { "id": 1, "type": "protection", "displayName": "방호복 회복제", "effect": "protection", "value": 10, "invPrefab": "invProtectRecovPrefab", "mapPrefab": "mapProtectRecovPrefab" },
  { "id": 2, "type": "time", "displayName": "시간 연장기", "effect": "time", "value": 10, "invPrefab": "invTimeRecovPrefab", "mapPrefab": "mapTimeRecovPrefab" }
]
```

| 필드 | 의미 |
|------|------|
| `id` | 종류 식별자 (1=방호복, 2=시간) |
| `type` / `effect` | 문자열 종류 |
| `value` | 회복량·연장 초 |
| `invPrefab` / `mapPrefab` | Resources 또는 경로 로드용 이름 |

## 4. 인벤 UI 규칙 (합의)

### 4.1 칸·스택

| 규칙 | 내용 |
|------|------|
| **1칸 = 1종류(id)** | 같은 id 획득 시 **새 칸이 아니라 count++** |
| **기본 4칸** | 항상 **빈 슬롯 이미지** 4개 표시 (`invEmptySlotPrefab`) |
| **5번째 종류~** | `Content`에 칸 **추가** + 가로 **ScrollRect** |
| Viewport | 약 **4칸 너비**만 보이게 |

### 4.2 선택·사용 (기존 키 유지)

| 입력 | 동작 |
|------|------|
| `C` / `V` | 회복 슬롯 이전 / 다음 |
| `Space` | 선택 슬롯 사용 → `count--`, 0이면 빈 칸 복귀 |

### 4.3 선택 표시 (UI)

- `Select` 마크 대신 **`dim`** — 선택된 칸은 dim **OFF**, 비선택·빈 칸은 dim **ON**.
- `RecoveryItemInventoryUI`에 반영 완료.

## 6. Hierarchy 권장 (GameScene)

```text
RecoveryInvenPanel          ← 신규 (중화 InventoryContainer와 분리)
└─ Scroll View
   ├─ Viewport (Mask)
   │  └─ Content (Horizontal Layout Group)
   │     └─ invEmptySlot × 4   ← 1단계
   └─ Scrollbar (선택)
```

`ItemManager` 슬롯(Z/X 중화)과 **같은 Transform 공유 금지**.

### 7.1 UI 표시 규칙 (합의·구현)

| 요소 | 규칙 |
|------|------|
| 빈 칸 | `invEmptySlotPrefab` — Name/Image/Count **비활성**, dim ON |
| 아이템 표시 | 칸 자식 **`InvItemView`** (`invProtectRecovPrefab` / `invTimeRecovPrefab`) |
| Image | `(0, 12.4)`, `44×44`, `preserveAspect` |

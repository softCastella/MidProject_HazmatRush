## 2. 경고 구간 (`WarningAndSpawn`)

### 2.1 멈추는 것 (프리즈)

| 대상 | 방법 |
|------|------|
| 플레이어 이동 | `player.canMove = false` |
| 타이머 | `timer.StopCountdown()` |
| 배경 스크롤 | `awaitingSpawn` → `PauseScroll` |
| 게임플레이 키 | Z/X, C/V/Space, K/I — `IsWarningFreeze` 동안 차단 |

### 2.2 계속되는 것

- BGM 재생 (dim 없음)
- 경고 문구 깜빡임 (`WarningTxt`)
- 튜토리얼 아이템 안내 (`GuideTxt.ShowItemSelectHintRoutine`)
- `Time.timeScale` — **1 유지** (전체 일시정지 사용 안 함)

### 2.3 해제 시점

- 오염원 **등장·페이드인 시작** 후: `canMove = true`, `timer.isRunning = true`, `awaitingSpawn = false`

## 3. 맵 잔존 회복 아이템 + 구간 전환

### 3.1 배경 스크롤

- 회복 아이템이 **착지 완료**(`IsLandedOnMap`)한 뒤 맵에 1개 이상 있으면 배경 스크롤 **정지**.
- 오염원 활성·경고 중(`awaitingSpawn`) 규칙과 **OR** 조건.

### 3.2 맵 이동 가능 시점

```
구간 오염원 전부 중화
    ↓
"오른쪽으로 이동하세요" 안내 (맵 이동 가능 신호)
    ↓
플레이어: 회복 아이템 수집 여부 자유 선택
    ↓
맵 끝 (mapEndX) 도달
    ↓
페이드 → 다음 구역
```

| 규칙 | 내용 |
|------|------|
| 즉시 페이드 | **금지** — 중화 직후 자동 맵 전환 없음 |
| 안내 문구 | 중화 직후 표시, 맵 끝 도달·페이드 직전까지 유지 |
| 잔존 아이템 | **맵 이동을 막지 않음** — 끝에 먼저 가도 전환 가능 |
| 전환 시 | 미수집 맵 아이템 `ClearMapRecoveryItems()` |
| 전환 후 | `ResetRange`, `segmentMovementUnlocked = false`, 배경 스크롤 일반 규칙 복귀 |

## 4. 스테이지 클리어 (마지막 구간)

### 4.1 맵 회복 아이템

- 클리어 연출(`ShowClear`) **직전** 맵에 남은 회복 아이템 → **인벤 자동 획득** (`AutoCollectMapRecoveryItems`).
- 동일 id는 Count 스택. 신규 id는 슬롯 추가 (`EnsureSlotRootCount`).
- 인벤 **가득 참 시나리오 없음** (현재 JSON 2종·동적 칸 확장).
- 자동 획득 후 맵 오브젝트 제거 → 클리어 애니 시 맵에 아이템 잔존 없음.

### 4.2 클리어 애니

| 단계 | 동작 |
|------|------|
| 시작 | `PlayClearAnim()` — `Player_Clear` 트리거, 루프 클립 재생 |
| 2초 | `clearAnimDelay` 경과 |
| 정지 | `FreezeClearAnim()` — `anim.speed = 0` (현재 프레임 고정) |
| 패널 | ClearSet + SFX |

- 클립 `Loop Time`은 에셋 그대로. **코드에서 2초 후 speed 0**이 정답 (1초 클립 2회 재생 후 포즈).

### 4.3 결과 패널

- 기존 합의 유지: 애니 **먼저** → `clearAnimDelay` 후 ClearSet ([Bug 2026-06-05 클리어·VFX](../Bug/2026-06-05-시각미상-클리어-가이드-중화VFX-fixes.md)).

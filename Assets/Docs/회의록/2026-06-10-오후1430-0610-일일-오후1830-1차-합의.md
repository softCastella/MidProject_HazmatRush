## 세션 오후 14:30 — 스테이지 BGM (`AudioManager`)

### 배경

- `stage_data.json`의 `bgmIndex`(0·1·2)와 무관하게 게임 BGM이 항상 0번처럼 들림.
- `AppScene` 전체 플로우와 `GameScene` 단독 Play 모두에서 `AudioManager`가 동작해야 함.

### 합의

| 항목 | 규칙 |
|------|------|
| **게임 BGM 주체** | `StageManager.LoadStage()` → `AudioManager.PlayStageBgm(bgmIndex)` |
| **씬 로드 시** | `GameScene` 진입만으로 `PlayGameBGM()`(0번 강제) **호출하지 않음** |
| **싱글톤 클립** | 중복 `AudioManager` 파괴 시 `CopyStageBgmClipsIfNeeded`로 `stageBgmClips` 병합 |
| **fallback** | `PlayGameBGM()`은 `StageManager` 없을 때만 (예: `ResumeAfterResult`) |

### 구현 상태

- ✅ `AudioManager.cs` — GameScene 자동 0번 재생 제거, 스테이지 클립 병합
- ✅ 실플레이 `bgmIndex` 전환 확인 완료 (1-2·1-3 스테이지별 BGM)

## 세션 오후 16:00 — 가이드·경고 팝업 (`GuideTxt` / `WarningTxt`)

### 배경

- `GuideTxt` / `WarningTxt`에 팝업 배경(`bg0`·`bg1`·`Bg`)을 넣었으나 코드는 텍스트만 켜서 배경이 안 보임.
- 긴 문구(Z/X 안내)에서 `bg0`+`bg1`이 겹쳐 보이는 문제가 반복됨.

### Hierarchy (GameScene · `GuideTxt`)

```text
GuideTxt (CanvasGroup)
├── bg0          ← 짧은 문구 (예: 오른쪽으로 이동)
├── bg1          ← 긴 문구 (예: Z키/X키 안내)
└── guide_text
```

`WarningTxt`: `WarningLabel` · `Bg` · `WarningMsg` — 표시 시 **세 요소 동시** ON/OFF.

### 합의

| 항목 | 규칙 |
|------|------|
| **단일 진입점** | `GuideTxt.ApplyPopup(Hidden / Short / Long)` 만 사용 |
| **상호 배타** | `bg0`와 `bg1`은 **동시에 켜지 않음** |
| **문구 길이** | `longMessageCharThreshold`(기본 16자) 초과 → `bg1`, 이하 → `bg0` |
| **자식 레이어** | `bg (1~3)`는 루트 Image와 중복 — 코드에서 **항상 OFF**, 루트만 사용 |
| **Inspector** | `popupShortRoot`=`bg0`, `popupLongRoot`=`bg1` 직접 연결 |
| **경고** | `WarningTxt.SetPopupVisible` — `Bg`·`WarningLabel`·`WarningMsg` 함께 깜빡임 |

### 금지

- `SetPopupVisible` / `ActivatePopupBg` 등 **여러 경로**로 팝업 켜기 재도입 금지.
- 긴 문구에 `bg0` 자식 `bg (1~3)` 강제 ON 금지 (이중 테두리 재발).

### 구현 상태

- ✅ `GuideTxt.cs`, `WarningTxt.cs`, `GameScene` Inspector 연결

- 밸브(가스) 씬에서 방호복 0 사망 시 오염원 HP바가 남음.
- HP바 숨김 후에도 **밸브 → Die(약 1초) → 밸브 → 사라짐** 애니가 반복되는 증상 **미해결** (집에서 수정 예정).

### 합의 (HP바)

| 항목 | 규칙 |
|------|------|
| **사망 시** | `GameManager.BeginPlayerDeathSequence` → `PollutantManager.HidePollutantHpBar()` |
| **접촉 루프** | `Pollutant` — 사망 직후 `UpdatePollutantHpBar` 전 `HideBars`, `FixedUpdate`에서도 사망 시 숨김 |

- 원인 후보: `SetValveAnimActive` / `StartDeathSequence`에서 `valveAnimActive=false` 후에도 `ApplyPlayerContactDamage`·트리거 경로가 밸브를 재설정.

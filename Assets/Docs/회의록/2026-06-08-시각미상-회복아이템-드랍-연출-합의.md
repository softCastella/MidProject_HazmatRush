## 1. 배경

- 회복 아이템 **인벤·픽업**은 2026-06-06에 1차 완료 ([회의록 2026-06-06](2026-06-06-시각미상-회복아이템-인벤-설계-합의.md)).
- **오염원 정화 드랍**은 `RecoveryItemManager` + `RecoveryItem.StartDropArc`로 구현되어 있었으나, 연출 수치가 맵 스프라이트 스케일과 맞지 않아 **아크가 안 보이는 것처럼** 보고됨.
- 실플레이·Console 로그로 원인 규명 후 수치·Y 오프셋·디버그 로그 반영.

## 2. 드랍 발생 조건 (기존 유지)

| 단계 | 동작 |
|------|------|
| 트리거 | 오염원 HP 0 → `Pollutant.FadeOutAndDestroy` |
| 확률 | 타입별 `dropChanceTypeA~D` (%) → 방호복 vs 시간 `dropProtectionChance` |
| 테스트 | `testAlwaysDrop` — 개발 중 100% 드랍, **빌드 전 OFF** |
| 프리팹 | `protectionItemPrefab` / `timeItemPrefab` → `mapProtectRecovPrefab` / `mapTimeRecovPrefab` |

맵에 **미리 배치된** 회복 아이템 스폰(`RecoveryItemSpawner`)은 본 합의 범위 밖 — 스크립트 누락 상태.

## 3. 아크 연출 규칙 (합의)

### 3.1 궤적

- 오염원 위치(+ Y 오프셋)에서 **위로 포물선** → **좌 또는 우**로 `dropLandOffsetX` 만큼 착지.
- 수식: `arc = 4 * jumpHeight * t * (1-t)`, X는 `Lerp(start.x, end.x, t)`.
- 아크 중 **픽업 콜라이더 OFF**, 착지 후 ON (`dropInProgress`).

### 3.2 Inspector 파라미터 (`RecoveryItemManager`)

| 필드 | 의미 | 튜닝 참고 |
|------|------|-----------|
| `dropYOffset` | 오염원 Y + 보정 (드랍·착지 기준) | 스프라이트가 땅에 묻히면 증가 (기본 30) |
| `dropJumpHeight` | 아크 최대 높이 | 맵 프리팹 스프라이트 ~86 유닛 기준, **수십~수백** 단위 |
| `dropLandOffsetX` | 착지 가로 거리 (± 랜덤) | jumpHeight와 비슷한 오더 권장 |
| `dropDuration` | 연출 시간(초) | 0.4~0.6 |

**중요:** jump/land 값은 **월드 유닛**이며, 맵 회복 프리팹·오염원 스프라이트 **픽셀/스케일**에 맞춰 Inspector에서 조절. 코드 기본값만으로 모든 스테이지에 맞지 않을 수 있음.

### 3.3 `RecoveryItem` 부착

- **맵 픽업 프리팹만** (`mapProtectRecovPrefab`, `mapTimeRecovPrefab`).
- 인벤 `inv*RecovPrefab`에는 부착하지 않음.

## 4. 디버그 로그 (합의)

`RecoveryItem.cs`에 아크 전용 로그 유지:

| 로그 | 시점 |
|------|------|
| `아크 시작` | `StartDropArc` — 시작·착지 좌표, jumpHeight, duration |
| `아크 정점` | t ≥ 0.5, 1회 |
| `아크 착지 완료` | 픽업 콜라이더 ON |
| `아크 생략` | duration ≤ 0 |

Console 필터: `RecoveryItem` / `RecoveryItemManager`.

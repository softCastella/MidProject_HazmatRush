|------|-----------|--------------|
| **클리어 패널** | 표시·별 OK, **버튼·키 입력 없음** | F1 동일 — 버튼 없음 |

## 3. 합의 — 결과 패널 (재조사 원칙)

### 3.1 타이밍

| 항목 | 규칙 |
|------|------|
| `gameEnded` 후 | `GameManager.Update`만으로 코루틴 `WaitForSeconds`에 의존 **금지** (`timeScale=0` 시 멈춤). |
| 클리어·게임오버 | **동일 방식**으로 `clearAnimDelay` / `dieAnimDelay` 후 패널 표시 — `unscaledDeltaTime` 타이머 1곳 (`Timer` 또는 `GameManager` public tick). |
| 패널·애니 | 애니 재생과 결과 패널 **동시 표시 금지** ([2026-06-05 클리어 fixes](../Bug/2026-06-05-시각미상-클리어-가이드-중화VFX-fixes.md) 유지). |

### 3.2 HUD·입력

| 항목 | 규칙 |
|------|------|
| 결과 표시 시 | `ItemContainer` + `InventoryContainer` (+ 필요 시 `InvLbContainer`) **숨김** — 회복·중화 HUD가 `Result_HUD` 레이캐스트 가리지 않게. |
| 금지 | HUD Canvas **전체 자식 일괄 `SetActive(false)`** (Timer 등 부수 중단). nested Canvas·CanvasGroup 해크 **무분별 추가 금지**. |
| 클리어 UI | `ClearPanelUI`는 **별·breakdown** 위주. 버튼 onClick은 **씬 연결 유지** (게임오버 `RetryBtn`과 동일). |
| 검증 | 클릭 시 Console `GoToNextStage 클릭` / `GoToTitleFromClear 클릭` 필수. |

### 3.3 롤백 (2026-06-08)

- 클리어 입력 패치 묶음 **효과 없음** + AnimationEvent 경고 동시 발생 → 아래 파일 **마지막 커밋으로 복구**:
  - `GameManager.cs`, `ClearPanelUI.cs`, `GameScene.unity`, `Timer.cs`
- **재작업 시** 위 §3.1~3.2 체크리스트로 검증 후 **최소 diff**만 적용.

## 4. 합의 — 회복 인벤 표시

### 4.1 표시 이름

| 소스 | 용도 |
|------|------|
| `recovery_items.json` → `displayName` | 인벤 칸 **Name** 텍스트 (런타임 `ApplyInvItemViewLayout`) |
| 프리팹·GameObject 이름 | 에디터 정리용 — **플레이 UI에 반영 안 됨** |

이름 변경 시 **JSON만** 수정. `EnsureFallbackDefs()` 하드코드와 불일치 주의.

### 4.2 아이콘 크기 (맵 PPU vs 인벤)

| 구분 | 규칙 |
|------|------|
| 맵 픽업 | `map*RecovPrefab` + `TimeWatch.png` 등 **맵용 PPU**(예: 5) 유지 |
| 인벤 | `ApplyInvItemViewLayout`이 Image를 **고정 sizeDelta**로 덮어씀 → 프리팹 scale/size만으로는 부족 |
| 시간연장 (id 2) | `InvImageSize` 44 대비 **1.5배 → 66px** (`InvImageSizeTime`) — 방호복(id 1)은 44 유지 |
| 대안 | 맵 스프라이트 건드리지 않고 **인벤 전용 타이트 크롭 스프라이트**를 `invTimeRecovPrefab`에만 할당 |

### 4.3 머지 실수 방지

- `RecoveryItemInventory` + `RecoveryItemInventoryUI`는 **`InventoryContainer`에만** 부착.
- **`GameManager`에 `RecoveryItemInventory` 추가 금지** — JSON 로드 2회·Update 중복.

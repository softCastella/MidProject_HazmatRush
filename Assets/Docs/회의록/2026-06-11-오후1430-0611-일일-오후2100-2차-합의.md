## 세션 오후 14:30 — 빌드 버전 표시 (`Application.version`)

### 배경

- Unity 버전 규약 피드백: Player Settings **Version**을 화면에 표시 (`Application.version`).
- 설정 메뉴 또는 화면 우하단 중 **타이틀만** 1차 적용.

### 합의

| 항목 | 규칙 |
|------|------|
| **값** | `Edit → Project Settings → Player → Version` (현재 `1.0`) |
| **표시** | TMP `"v" + Application.version` |
| **위치** | `TitleScene` · `TItle_HUD_Canvas` **우하단** (`VersionTxt`) |
| **범위** | 게임·일시정지·로딩은 **미적용** (요청 시 확장) |

### 구현 상태

## 세션 오후 17:00 — 씬 전환 페이드 색상

### 배경

- 페이드 in/out 색이 구간마다 달라 보인다는 피드백.
- [2026-06-06 씬전환 Bug](../Bug/2026-06-06-시각미상-씬전환-스플래시-인트로-fixes.md)는 타이틀→인트로 **흰색** 합의였으나, 일반 관습(씬 전환=검정)과 맞추기로 **정책 변경**.

### 합의 — 페이드 색

| 구간 | 색 | 비고 |
|------|-----|------|
| **스플래시 로고 페이드인/아웃** | **흰 배경** + 로고 alpha | 브랜드·로고 연출 유지 |
| **스플래시 → 타이틀** | **검정** 오버레이 (`fadeToBlackDuration` 기본 0.35s) | 로고 사라진 뒤·씬 활성화 직전 |
| **타이틀 → 인트로** | **검정** 암전 0.25s | `TitleSceneFade` |
| **인트로 진입** (Start 경로) | **검정** 1→0 페이드인 0.8s | `AutoScrollIntro.fadeInFromTitle` |
| **인트로 → 로딩** | **검정** 0.5s | 기존 유지 |
| **로딩 ↔ 게임 · 맵 전환** | **검정** | 기존 유지 |

### 금지·주의

| 항목 | 내용 |
|------|------|
| 스플래시→타이틀 | 로고 연출 **뒤** 검은 암전만. 스플래시 **로고 페이드인**은 흰 배경 유지. |
| 타이틀→인트로 | `fadeInFromTitle` 시 인트로 `Awake`에서 오버레이 **alpha 1(불투명)** 로 시작 — 0이면 번쩍임 재발. |
| 이중 페이드 | 스플래시 검은 암전 + 타이틀 **다시** 페이드인 넣지 않기 (타이틀 즉시 표시). |
| Continue | 인트로 생략 → 로딩만 (흰 체인 없음). |

### 구현 상태

- ✅ `SplashController.cs` — `fadeOverlay` · `fadeToBlackDuration`
- ✅ `TitleSceneFade.cs` — 검정 오버레이·카메라
- ✅ `AutoScrollIntro.cs` — 타이틀 진입 검정 페이드인
- 🟡 [0606 씬전환 Bug](../Bug/2026-06-06-시각미상-씬전환-스플래시-인트로-fixes.md) §6·§7 **흰색** 문구 — 본 합의로 **대체** (역사 기록은 유지)

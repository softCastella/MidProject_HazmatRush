## 세션 4차 — 플레이어·배경·걷기 애니 체감 속도

### 배경

- **1차 구간:** 플레이어 `moveSpeed` 이동 + 배경 UV `scrollSpeed` 스크롤이 **동시**에 돌아가 빠르게 느껴짐.
- **오염원 등장 이후:** `PollutantManager.ShouldPauseBackgroundScroll()` → 배경 `PauseScroll()` — `moveSpeed`는 그대로인데 배경만 멈춰 **느리게** 느껴짐.
- 걷기 스프라이트(`Player_Move`) 재생 속도와 실제 이동·배경 흐름 사이 **간극** 피드백.

### 합의 — 기본 이동·배경 쌍 (`Player` · `Background`)

| 항목 | 현재 값 (`GameScene` / 프리팹) | 비고 |
|------|-------------------------------|------|
| `moveSpeed` | **200** | `Player` 프리팹 · 코드 기본 400과 다를 수 있음 — **씬·프리팹 우선** |
| `scrollSpeed` | **0.2** (`GameScene` Background 오버라이드) | 프리팹 `Background0` 기본 **0.15** |
| 1:1 참고 | `scrollSpeed ≈ moveSpeed / 1920` | 200이면 이론 ~0.104 — **체감** 맞춤으로 0.2 유지·Play 튜닝 |

- [0609 합의](2026-06-09-오후1227-0609-일일-오후1700-2차-합의.md): **`moveSpeed`만 내리고 `scrollSpeed` 방치 금지** — 둘 다 인스펙터에서 같이 조절.

### 합의 — 배경 **잠금** 시 플레이어 가속

| 항목 | 규칙 |
|------|------|
| 조건 | `PollutantManager.IsBackgroundScrollLocked()` — 경고 대기·오염원 활성·맵 회복 아이템·맵 전환 등 **기존 배경 Pause와 동일** |
| 배율 | `Player.bgLockedSpeedMultiplier` — `GetMoveSpeed()`에서 `moveSpeed`에 곱함 |
| `GameScene` | **1.7** (코드 기본 1.5) → 잠금 중 유효 **340** (= 200 × 1.7) |
| 1차 자유 이동 | 입력 연동 배경 스크롤 구간 — **배율 미적용** (`Background.isPaused` 단독으로 판정하지 않음) |

### 합의 — 걷기 애니 간극

| 항목 | 규칙 |
|------|------|
| 전환 | `anim.SetInteger("State", …)` — Idle(0) / Move(1) (기존 유지) |
| 튜닝 축 | `moveSpeed` · `scrollSpeed` · `bgLockedSpeedMultiplier` · Animator **`Player_Move` 상태 Speed** 또는 클립 `SampleRate` |
| 배경 정지 구간 | 이동은 `bgLockedSpeedMultiplier`로 보정 — 애니는 별도 Speed로 **미끄러짐** 줄이기 |

### 금지

- 배경 입력 정지(`pauseWhenPlayerStops`)만으로 가속 ON — **Manager 잠금**만 사용.
- 전투 중 `moveSpeed` 인스펙터만 올리고 배경·애니는 그대로 — 세 축 **함께** Play 확인.

### 구현 상태 (4차)

- ✅ `PollutantManager.IsBackgroundScrollLocked()`
- ✅ `Player.GetMoveSpeed()` · `bgLockedSpeedMultiplier`
- ✅ `GameScene` — `moveSpeed` 200 · `scrollSpeed` 0.2 · `bgLockedSpeedMultiplier` 1.7
- 🟡 걷기 애니 Speed — 필요 시 `Player.controller` `Player_Move` 상태에서 추가 미세 조절

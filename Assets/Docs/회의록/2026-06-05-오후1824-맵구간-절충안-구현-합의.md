## 1. 배경

- 오전 회의에서 정리한 방향(트리거 통일, Player 이동 공식 유지)을 바탕으로 **실플레이 테스트** 진행.
- 오염원 **통과(뚫기)** 는 해결됐으나, **맵당 2마리·맵 전환·가이드·스폰 큐** 등 기획과 코드 불일치가 드러남.
- 프리로드(`spawnQueue` + `preloadedQueue`)는 유지하기로 함.

---

## 2. 합의한 게임 규칙 (절충안)

### 2.1 스테이지 · 맵 · 오염원 수

| 개념 | 규칙 |
|------|------|
| **스테이지** | `totalPollutant` = 스테이지 전체 처리 수 |
| **맵(화면)** | 맵당 **1~2마리**, `mapPollutants` 배열로 분할 (예: `[2,1]`) |
| **프리로드** | 로딩 시 스테이지 전체 `spawnQueue` 확정, **현재 맵 구간만** `preloadedQueue` 슬라이스 |

### 2.2 이동 범위

| 단계 | 이동 범위 |
|------|----------|
| 가이드 종료 ~ **첫 오염원 등장 전** | 1차 이동: `-785` ~ `-403` |
| **첫 오염원 등장 후** (맵당 1회) | `UnlockMapSegmentMovement()` — `-785` ~ `mapEndX`(769) |
| **맵 전환 후** | `ResetRange()` — 다시 1차 구간부터 |

- 오염원 위치마다 `GrowRange` / `GetEdgeX`로 범위를 조이지 **않음**.
- 플레이어는 오염원 **스프라이트·콜라이더를 통과**할 수 있음.

### 2.3 접촉 · HP

- **트리거 겹침** 시에만 방호복·오염원 HP 처리.
- 접촉 해제 시 오염원 HP **초기화** (A~D 동일).
- 데미지 처리: `OnTriggerStay2D` + `Time.deltaTime` (`FixedUpdate` 접촉 루프 제거).

### 2.4 맵 클리어 · 전환

1. 그 맵에 할당된 오염원 **전부 제거**
2. (다음 맵이 있으면) **「오른쪽으로 이동하세요」** 안내
3. 플레이어가 오른쪽 끝(`mapEndX`)까지 이동 → 페이드 → 시작 위치 스냅 → 다음 맵 프리로드
4. **마지막 맵**은 맵 전환 없이 **스테이지 클리어 패널**

### 2.5 가이드 문구

| 구분 | 1-1 (튜토리얼) | 1-2 이후 |
|------|----------------|----------|
| 시작 가이드 | ✅ | ❌ |
| 경고 후 Z/X 아이템 안내 | ✅ | ❌ |
| 맵 클리어 후 「오른쪽으로 이동하세요」 | 다음 맵 있을 때만 | 동일 |
| 오대응 패널티 안내 | ✅ (기존 유지) | ✅ |

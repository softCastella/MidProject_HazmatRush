QA TC — MidProject

QA팀 배포용 Test Case · 2026-06-10 · Unity 6000.4.8f1 · 플레이어가 완성된 기능을 끝까지 쓸 수 있는가 중심

진행 방법
A. 전체 — AppScene ▶ Play → 1~2(씬 흐름) → 4~7(씬 상세) → 8~14(GameScene)
B. 게임만 — GameScene ▶ Play → 8~14
3) 한 단계 = 한 씬·한 동작 · 「정상 결과」 보이면 ✓ · Fail 칸에 기록
조작: ←→/AD · Z/X · C/V·Space · K/I · ESC · F1 강제 클리어
Part A — 흐름 (1~3) · Part B — 씬 상세 (4~7) · Part C — GameScene (8~14, 14=선택)

시나리오 1 — 씬 이동 (첫 시작)

목적: 저장 없이 시작하기로 App부터 GameScene까지 씬이 한 칸씩 이어지는지 확인. (연출·BGM 등 세부는 시나리오 4~7)

✓#단계시나리오정상 결과 (화면)Fail 시
1-1AppScene AppScene Play Play 직후 App 씬 표시 · "No cameras rendering" 없음 카메라 경고·멈춤
1-2→ Splash 자동 전환 대기 SplashScene으로 바뀜 스플래시 없음·검은 화면 고정
1-3→ Title 스플래시 연출 종료까지 대기 TitleScene으로 바뀜 타이틀 안 뜸
1-4→ Intro 저장 없을 때 시작하기 클릭 IntroStoryScene으로 바뀜 무반응·로딩/게임 직행
1-5→ Loading 인트로 스크롤 종료까지 대기 LoadingScene으로 바뀜 인트로에서 멈춤
1-6→ Game 로딩 연출 종료까지 대기 GameScene · 스테이지 1-1 무한 로딩·게임 미진입

시나리오 2 — 씬 이동 (이어하기)

목적: 중간 저장 후 타이틀 복귀 시 이어하기 경로가 Intro 없이 Loading → Game으로 이어지는지 확인. (준비: 1-1 플레이 후 ESC·결과 패널 등으로 타이틀 복귀, 또는 저장 데이터 있는 상태)

✓#단계시나리오정상 결과 (화면)Fail 시
2-1TitleScene 저장 있는 상태로 TitleScene 진입 이어하기 버튼 노출 시작하기만 보임
2-2→ Loading 이어하기 클릭 Intro 없이 LoadingScene으로 바뀜 인트로 재생·무반응
2-3→ Game 로딩 연출 종료까지 대기 GameScene · 마지막 진행 스테이지에서 시작 항상 1-1·무한 로딩

시나리오 3 — 스테이지 이동 (1-1 → 1-3)

목적: 스테이지마다 다른 BGM·배경으로 시작하는지 확인. 빠른 검증은 GameScene에서 F1 강제 클리어로 다음 스테이지 진행.

✓#단계시나리오정상 결과 (화면)Fail 시
3-11-1 시작 GameScene · 스테이지 1-1 진입 배경·BGM이 1-1용(첫 곡) · 가스(D) 위주 구성 배경·BGM 어긋남
3-21-2 전환 F1 강제 클리어 또는 정상 클리어 후 다음 스테이지 배경이 1-1과 다름 · BGM이 다른 곡으로 바뀜 배경·BGM 동일
3-31-3 전환 다시 F1 또는 클리어로 1-3 진입 배경·BGM이 1-2와 또 다름 · A/B/C/D 혼합 스테이지 항상 0번 BGM·같은 배경
3-4플레이 가능 각 스테이지에서 가이드 후 이동·타이머 확인 전환 직후에도 이동·타이머·UI 정상 전환 후 입력 불가·UI 깨짐

시나리오 4 — SplashScene

목적: 로고 연출·SFX가 의도대로 재생되는지 확인.

✓#단계시나리오정상 결과 (화면)Fail 시
4-1로고 페이드인 SplashScene 진입 직후 관찰 로고가 약 0.65초에 걸쳐 서서히 나타남 로고 없음·즉시 점프
4-2로고 애니 페이드인 이후 로고 확대·샤인(반짝) 연출 후 페이드아웃 연출 없이 정지
4-3SFX 페이드인 시작 직후 청취 스플래시 SFX 1회 (BGM은 아직 없음) 무음·BGM이 먼저
4-4타이틀 전환 연출 종료까지 대기 TitleScene으로 자연스럽게 전환 (긴 검은 화면 대기 없음) 멈춤·중복 로딩

시나리오 5 — TitleScene

목적: TitleScene 안에서 BGM·배경·버튼·클릭 반응이 의도대로인지 확인. (씬 간 전환은 시나리오 1·2)

✓#단계시나리오정상 결과 (화면)Fail 시
5-1첫 플레이 UI 저장 없을 때 TitleScene 진입 타이틀 BGM · 배경 · 시작하기 노출 이어하기만·UI 없음
5-2시작하기 시작하기 클릭 버튼 SFX · 흰 페이드 시작 무반응·음소거
5-3중간 복귀 UI 저장 있는 상태로 TitleScene 진입 (ESC·결과 패널 타이틀 등) 이어하기 버튼 노출 이어하기 없음
5-4이어하기 이어하기 클릭 버튼 SFX · 페이드 시작 무반응

시나리오 6 — IntroStoryScene

목적: 첫 시작 시 인트로 스토리 연출이 정상 재생·종료되는지 확인. (이어하기 경로에는 해당 없음)

✓#단계시나리오정상 결과 (화면)Fail 시
6-1진입 시나리오 1-4 직후 IntroStoryScene 관찰 스토리 스크롤·텍스트 연출 재생 빈 화면·멈춤
6-2종료 스크롤 끝까지 대기 (또는 스킵 입력 시) 연출 종료 후 다음 씬으로 넘어갈 준비 (Loading) 영구 고정

시나리오 7 — LoadingScene

목적: 로딩 연출·안내 문구가 플레이어에게 조작법을 전달하는지 확인.

✓#단계시나리오정상 결과 (화면)Fail 시
7-1경고 테이프 좌측 상단 테이프 2줄 관찰 (5초 이상) 2줄이 서로 다른 속도로 움직임 · 방향도 다름(한 줄은 좌→우, 한 줄은 우→좌) 정지·같은 속도·한 줄만
7-2로딩 스피너 중앙 스피너 관찰 균일하게 회전·반복 (끊김·역회전 없음) 멈춤·깜빡임
7-3가이드 순환 중앙 상단 안내 텍스트 10초 이상 관찰 이동·Z/X·C/V·K/I·ESC 안내가 순환 문구 없음·한 줄 고정
7-4가이드 전환 문구가 바뀔 때 관찰 페이드로 전환 · 문구 겹침 없음 겹침·깜빡임
7-5게임 진입 로딩 종료까지 대기 페이드 아웃 후 GameScene · 플레이어·HUD 표시 무한 로딩·검은 화면

시나리오 8 — GameScene · 시작 · 가이드 · 첫 이동

목적: 튜토리얼 후 짧은 구간만 걸을 수 있고, 오염원 등장 전후로 이동 범위가 바뀌는지 확인.

✓#단계시나리오정상 결과 (화면)Fail 시
8-1게임 진입 GameScene Play (또는 시나리오 1·7 완료 후) 플레이어·UI·타이머·배경·방호복 바 표시 검은 화면·멈춤
8-2가이드 중 시작 안내 문구가 나온 동안 ←→ 입력 캐릭터가 움직이지 않음 · 짧은 팝업(bg0) 배경 보임 가이드 중 이동됨
8-3가이드 후 안내가 끝난 뒤 좌우 이동 이동 가능 · 타이머 감소 · 배경이 함께 흐름 이동·타이머·배경 중 하나라도 안 됨
8-41차 구간 한계 오른쪽 끝까지 이동 (오염원 없을 때) 일정 지점에서 더 이상 오른쪽으로 못 감 끝없이 오른쪽으로만 감
8-5K / I K · I 키로 가이드 패널 열기/닫기 키 가이드·아이템 가이드 패널 토글 패널 안 뜸

시나리오 9 — GameScene · 오염원 경고 · 등장

목적: 경고 때 게임 전체가 멈춘 것처럼 보이지 않고, 필요한 것만 멈추는지 확인.

✓#단계시나리오정상 결과 (화면)Fail 시
9-1경고 발생 가이드 후 오른쪽으로 2~3초 이동 경고 문구·깜빡임 · Bg+라벨+메시지 함께 표시 경고 없음
9-2경고 중 경고 중 ←→ · Z/X · C/V 입력 시도 캐릭터·배경·타이머 멈춤 · BGM은 계속 이동·타이머 됨
9-3Z/X 안내 긴 안내 문구(Z/X) 표시 시 긴 팝업(bg1)만 · bg0와 겹치지 않음 이중 테두리·배경 없음
9-4오염원 등장 연출 종료까지 대기 오염원 페이드인 · 이후 이동·타이머·Z/X 재개 오염원 없음·영구 잠금
9-5이동 확장 첫 오염원 등장 후 오른쪽 끝까지 이동 경고 전보다 더 오른쪽까지 이동 가능 여전히 짧은 구간

시나리오 10 — GameScene · 오염원 접촉 · 중화

목적: 맞는/틀린 도구·접촉 유지·가스(D) 연출 확인.

✓#단계시나리오정상 결과 (화면)Fail 시
10-1접촉 오염원에 닿기 · 닿은 채 5초 이동 방호복·오염원 HP바 · 접촉 끊기지 않음 바 없음·끊김
10-2틀린 도구 Z/X로 틀린 도구 선택 후 접촉 방호복만 감소 · 오염원 HP·중화 VFX 없음 오염원 HP 감소·VFX
10-3맞는 도구 맞는 중화제 선택 후 접촉 (A~C) 방호복 감소 + 오염원 HP 감소 + 중화 VFX HP·VFX 없음
10-4가스(D) 가스 오염원 · 가스밸브 정답 접촉 밸브 애니·밸브 SFX · 중화 VFX 없음 VFX만 켜짐·접촉 안 됨
10-5제거 후 오염원 제거 후 Z/X로 다른 도구 선택 선택한 중화 아이템 유지 (스캐너로 강제 초기화 없음) 제거 직후 리셋

시나리오 11 — GameScene · 회복 아이템 (정화 드랍)

목적: 오염원 제거 후 회복 아이템 드랍·인벤·배경 스크롤 확인. (맵 고정 스폰 없음)

✓#단계시나리오정상 결과 (화면)Fail 시
11-1드랍 오염원 중화 제거 (드랍 발생 시) 회복 아이템이 위로 튀었다 좌/우 착지 드랍 없음·땅 묻힘
11-2픽업 아이템에 접촉 · C/V·Space 사용 인벤 아이콘·이름·Count · 방호복/시간 회복 반영 인벤·효과 없음
11-3스택 같은 회복 아이템 다시 획득 Count만 증가 칸 중복·표시 깨짐

시나리오 12 — GameScene · 맵 구간 · 다음 구역

목적: 구간 오염원 전부 처리 후 안내대로 이동해 다음 맵으로 넘어가는지 확인.

✓#단계시나리오정상 결과 (화면)Fail 시
12-1구간 클리어 현재 맵 예정 오염원(가스 포함) 전부 처리 「오른쪽으로 이동」류 안내 · 즉시 전체 페이드 없음 미처리인데 안내·이동 가능
12-2맵 전환 안내대로 맵 오른쪽 끝까지 이동 페이드 후 다음 구역 · 배경·오염원 준비 끝까지 가도 전환 안 됨

시나리오 13 — GameScene · 스테이지 클리어 · 사망

목적: 클리어·사망 결과 연출 순서 확인 (2026-06-10 기준). 한 단계 = 한 연출 구간.

✓#단계시나리오정상 결과 (화면)Fail 시
13-1클리어 애니 스테이지 최종 클리어 Clear 애니 약 2초 재생 애니 없음
13-2클리어 패널 Clear 애니 종료 후 관찰 클리어 결과 패널·별 표시 (애니와 동시 아님) 애니와 패널 동시
13-3Die 애니 방호복 0까지 접촉 Die 포즈 약 2초 즉시 패널·밸브 루프
13-4페이드 아웃 Die 애니 직후 관찰 플레이어 페이드 아웃 약 0.5초 페이드 없음
13-5게임오버 패널 페이드 종료 후 관찰 약 1초 여백 뒤 게임오버 패널 + SFX 페이드와 동시·너무 빠름
13-6가스 사망 가스+가스밸브 접촉 중 방호복 0 Die만 · 밸브 재진입 없음 · HP바 숨김 밸브↔Die 반복
13-7타이틀 복귀 게임오버 패널에서 타이틀 버튼 TitleScene 전환 · 이어하기 노출(저장 시) 타이틀 안 감

시나리오 14 — GameScene · 이동·배경 체감 (선택)

주관 체감. 애매하면 메모만 남기면 됨.

✓#단계시나리오정상 결과 (화면)Fail 시
14-1속도 가이드 후 5초 이상 이동 배경·캐릭터 속도 비율 자연스러움 배경만 비정상

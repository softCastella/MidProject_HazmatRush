배포받은 실행 파일(.exe)로 게임을 켠 뒤 플레이하며, 기능이 잘 되는지 · 무엇이 느껴지는지 체크하거나 적어 주세요.

💡사전 배경 지식💡

이 게임은?

Hazmat Rush는 2D 횡스크롤 오염 대응 게임입니다. 방호복을 입은 캐릭터가 좌우로 이동하며, 맵에 나타나는 오염원에 닿으면 방호복이 줄어듭니다. 맞는 중화 도구를 고른 뒤 오염원에 닿아야 오염을 제거할 수 있고, 틀린 도구면 방호복만 계속 깎입니다. 오염원을 모두 처리하면 다음 구역으로 넘어가며, 방호복이 0이 되거나 시간이 다하면 게임 오버입니다.

처음이어도 괜찮습니다. 아래 용어 설명을 보면서, 각 문항의 「어떻게 할지」만 따라 하시면 됩니다.

안내 문구 순서 (1-1 스테이지 · 처음 플레이 기준)

이 게임은 플레이어의 이동을 제한하거나 풀어주는 구간이 존재합니다. 잘 읽어보시고 안내를 따라주세요.

같은 문구가 두 번 나올 수 있습니다. 언제 뜨는지로 구분해 주세요.

  1. 게임 화면 진입 직후 — 안내 팝업
    오른쪽으로 이동하세요
    이 문구가 사라진 뒤부터 이동 · 시간 · 배경이 시작됩니다. (문항 1 · 2)
  2. ①이 끝난 뒤 오른쪽으로 2~3초 걸었을 때 — 경고 표시 (깜빡임)
    [경고] (오염물질 이름) 오염물질 발견
    예: [경고] 가스 오염물질 발견 · 이때 이동 · 시간이 잠시 멈춤 (문항 3)
  3. 경고 직후 — 안내 팝업 (긴 팝업)
    Z키(왼쪽)/X키(오른쪽)로 대응 아이템을 골라주세요
    문항 4
  4. (선택) 틀린 도구로 닿았을 때 — 안내 팝업
    잘못된 아이템 선택으로 2초 후에 아이템선택이 가능합니다.
    1-1에서만 · 문항 6
  5. 이 구역 오염원을 전부 없앤 뒤 — 안내 팝업 (①과 같은 문구, 다른 타이밍)
    오른쪽으로 이동하세요
    맵 끝까지 가면 다음 구역으로 넘어감 (문항 9)
진행 방법 (PC 빌드)
1) 받은 폴더 안 .exe를 더블클릭해 게임을 실행합니다.
2) 타이틀에서 시작하기 → (처음이면 인트로 · 로딩) → 게임 화면까지 들어갑니다.
3) 게임 화면에서 문항 1번부터 순서대로 플레이합니다.
4) 각 항목 오른쪽 네/아니오를 체크하고, 문항마다 완료 · 그외 의견을 적어 주세요.
5) 다 끝나면 맨 아래 MD 파일로 저장을 눌러 결과 파일을 제출합니다. (MD = 메모 형식의 텍스트 파일)

exe와 같은 폴더의 _Data 폴더는 함께 두어야 게임이 실행됩니다. exe만 따로 옮기지 마세요.


조작 참고:
  • K / I : 조작 · 아이템 설명 창 열기/닫기
  • ESC : 일시정지
  • ← → 또는 A / D : 캐릭터 좌우 이동
  • Z / X : 경고 창에서 중화 도구 왼쪽 · 오른쪽으로 바꾸기
  • C / V : 인벤토리에서 회복 아이템 왼쪽 · 오른쪽으로 바꾸기
  • Space : 선택한 회복 아이템 사용
  • F1 : (테스트 빌드에만) 스테이지를 바로 클리어 — 10번 문항을 빠르게 볼 때

1

게임 시작 · 화면 정보 확인 · 「오른쪽으로 이동하세요」 팝업 이후 테스트

첫 안내 팝업이 사라진 뒤 이동 · 시간 · 배경

  1. 게임 화면에 들어오면 캐릭터, 방호복 막대, 남은 시간, 아이템창, HP바, 배경 등이 보이나요?
  2. 화면 중앙에 (게임 시작 직후 첫 번째 안내) 「오른쪽으로 이동하세요」 팝업이 뜨나요?
  3. 그 팝업이 서서히 사라진 뒤 ←→로 이동이 되며 시간이 줄고 배경이 함께 움직이나요?
정상: HUD가 표시되고 · 「오른쪽으로 이동하세요」 팝업이 사라진 뒤 이동 · 시간 · 배경이 동작합니다
2

「오른쪽으로 이동하세요」 팝업 노출 중 이동 잠금 · K/I 설명 창 관련 테스트

첫 안내 팝업이 떠 있는 동안 · K/I 도움말

  1. 「오른쪽으로 이동하세요」 팝업이 떠 있는 동안 ←→를 눌러도 캐릭터가 움직이나요?
  2. K / I 키로 조작 설명 · 아이템 설명 창이 열리고 닫히나요? (버튼 한번: 열림/버튼 두번: 닫힘)
정상: 첫 「오른쪽으로 이동하세요」 팝업 중에는 움직이지 않고(2-1 아니오) · K/I 키로 설명 창을 켜고 끌 수 있습니다
3

오염원 경고 · 등장 · 이동 범위 확장 관련 테스트

첫 오염원이 나오기 전 · 후에 무슨 일이 일어나는지 관찰

  1. 첫 「오른쪽으로 이동하세요」 팝업이 사라진 뒤, 오른쪽으로 2~3초 걸어갔을 때 「[경고] ○○ 오염물질 발견」 경고창(깜빡임)이 뜨나요? (안내 팝업과 다른 창)
  2. 경고가 뜬 동안 캐릭터와 시간이 멈추고, 배경음악은 계속 나오나요?
  3. 오염원이 서서히 나타난 뒤 다시 이동할 수 있나요?
  4. 오염원 등장 후, 경고 전보다 오른쪽으로 더 멀리 갈 수 있나요?
정상: 경고 → 등장 연출이 자연스럽고 · 오염원 등장 후 더 멀리 이동할 수 있습니다
4

중화 도구 선택 (Z/X키키) 관련 테스트

오염원에 쓸 도구를 고르고 화면에 보이는지 관찰

  1. 경고 직후 「Z키(왼쪽)/X키(오른쪽)로 대응 아이템을 골라주세요」 팝업이 보이나요?
  2. Z / X 키로 왼쪽 하단 아이템창의 중화 도구를 바꿔서 선택할 수 있나요?
  3. 아이템 창에서 고른 도구의 칸이 다른 아이템 칸보다 밝게 보이나요?
정상: Z/X 키를 누르면 바로 바뀌고 · 지금 고른 도구가 다른 도구보다 밝게 보입니다
5

오염원 접촉 · 방호복 · 체력 막대 관련 테스트

플레이어가 오염원과 닿은 채로 있을 때 오른쪽 상단 방호복 HP(내구도) 수치가 줄고, 떨어지면 어떻게 되는지 관찰

  1. 오염원에 닿은 채 접촉이 유지되나요?(접촉유지시 HP감소가 있습니다.)
  2. 닿는 동안 방호복 수치 · 오염원 체력 막대가 보이나요?
  3. 오염원에서 떨어지면 막대가 사라지고, 오염원 체력이 처음으로 돌아가나요?
정상: 닿는 동안 막대가 유지되고 · 떨어지면 막대가 사라지며 오염원 체력이 초기화됩니다
6

맞는/틀린 도구 · 중화 이펙트 관련 테스트

맞는 도구만 오염원을 제거하는지 관찰

6-4 확인 전에 읽기 — 구역 · 오염원 개수
  • 구역 = 지금 걷고 있는 맵 한 화면. 오염원을 다 처리한 뒤 오른쪽 끝까지 가면 다음 구역으로 넘어갑니다 (9번 문항).
  • 스테이지 1-1 첫 구역에는 오염원이 2마리 나옵니다 (가스 2체). 한 마리만 없애도 맵에는 아직 오염원이 남아 있습니다.
  • 6-4에서 볼 것: 첫 번째만 없앤 직후 → 아직 한 마리 남음 → 고른 중화 도구가 그대로인지 (스캐너로 안 바뀌는지)
  • 6-4가 아닌 것: 2마리 전부 없앤 뒤에는 스캐너로 돌아가고 「오른쪽으로 이동하세요」 안내가 뜨는 것이 정상입니다. 이때 스캐너 복귀는 버그가 아닙니다.
  1. Z/X 키로 틀린 도구를 고른 뒤 닿으면, 방호복 HP만 줄고 오염원 체력 변화 · 이펙트는 있나요?
  2. (1-1) 틀렸을 때 「잘못된 아이템 선택으로 2초 후에 아이템선택이 가능합니다.」 안내가 뜨나요?
  3. 올바른 중화제를 고른 뒤 닿으면, 방호복도 줄지만 오염원 체력도 줄고 중화 이펙트(파란 효과)가 나오나요?
  4. 1-1 첫 구역에서 첫 번째 오염원만 없앤 직후, 맵에 아직 오염원이 남아 있는데도 고른 중화 도구가 그대로인가요? (스캐너로 바뀌지 않음)
정상: 맞을 때만 오염원 체력 · 이펙트(6-3 네) · 틀리면 방호복만 감소(6-1 아니오) · 같은 구역에 오염원이 남아 있을 때 하나만 없앤 직후에는 고른 도구 유지(6-4 네) · 구역 안 오염원을 전부 없앤 뒤 스캐너 복귀는 정상(6-4 대상 아님)
7

가스 오염원 · 밸브 연출 관련 테스트

가스는 밸브 연출(플레이어 애니메이션)만 나오고, 일반 중화 이펙트(파란 효과)는 없음

  1. 가스밸브(맞는 도구)를 고르고 가스 오염원에 닿으면, 밸브가 돌아가고 효과음이 나나요?
  2. 가스 처리 시 일반 중화 이펙트(파란 효과)가 나오나요??
  3. 가스에 닿는 동안 방호복 HP가 정상적으로 줄어드나요?
정상: 밸브 잠그는 움직임 · 효과음만 나오고 · 중화 이펙트는 없으며 · 닿으면 방호복이 정상적으로 감소합니다
8

회복 아이템 · 인벤토리 · 사용 관련 테스트

오염원 제거 후 떨어진 아이템 획득하고 쓰기

  1. 오염원을 없앤 뒤 회복 아이템이 튀어 올랐다 땅에 떨어지고, 닿아서 획득할 수 있나요? (획득시 오른쪽 하단 인벤토리에 아이템이 생깁니다)
  2. 화면 아래 인벤토리 칸에 아이콘(이미지) · 이름 · 개수가 보이나요?
  3. C / V로 고른 뒤 Space로 사용하면, 방호복 또는 남은 시간이 회복되나요?
  4. 같은 아이템을 또 획득하면 칸이 늘지 않고 개수만 늘어나나요?
정상: '오염원 제거 → 아이템 생성 → 획득 → 인벤토리 표시 → 사용'까지 한 흐름이고 · 같은 아이템은 개수만 증가합니다
9

구역 클리어 · 다음 맵 이동 관련 테스트

이 구역 오염원을 다 없앤 뒤 다음으로 넘어가기

  1. 오염원을 전부 없애기 전에는 맵 끝까지 가도 다음 구역으로 넘어가나요? (한 구역(현재 화면)에 2체 이상의 오염원이 있을 경우)
  2. 한 구역(현재 화면)에서 오염원을 전부 없앤 뒤, 두 번째 「오른쪽으로 이동하세요」 팝업이 뜨나요?
  3. 그 안내 후 맵 오른쪽 끝까지 걸어가면, 화면이 서서히 어두워졌다가 다음 구역으로 넘어가나요?
정상: 전부 없애기 전에는 넘어가지 않고 · 없앤 뒤 안내 → 화면 전환 → 다음 구역(한 스테이지내 이미지는 동일)으로 이어집니다
10

스테이지 클리어 · 사망 결과 화면 관련 테스트

깨거나 죽었을 때 연출 순서 (테스트 빌드면 F1로 클리어 빠르게 확인 가능)

  1. 스테이지를 클리어하면(또는 테스트 빌드에서 F1), 승리 동작 약 2초 뒤에 결과 창이 뜨나요? (동시에 뜨지 않음)
  2. 방호복이 0이 되면, 쓰러지는 동작 → 캐릭터가 서서히 사라짐 → 게임 오버 창 순서로 진행되나요?
  3. 가스를 잠그다 죽을 때 밸브 잠그는 애니메이션 후에 쓰러지는 동작으로 이어지나요?
정상: 동작 연출이 끝난 뒤 결과 창이 뜨고 · 사망할 때 순서가 자연스럽습니다

1. 게임 개요

Hazmat Rush는 방호복을 입은 캐릭터가 좌우로 이동하며, 맵에 나타나는 오염원을 맞는 중화 도구로 제거하는 2D 횡스크롤 게임입니다.

게임 이름Project Hazmat Rush (해즈멧 러시)
게임 방식맵을 걸으며 오염원에 접촉하고, Z/X로 고른 도구로 중화합니다.
플레이 목표각 구역의 오염원을 모두 제거하고, 스테이지를 클리어합니다.
승리 조건스테이지의 모든 오염원을 중화하고 클리어 결과 화면이 나옵니다.
패배 조건방호복 HP가 0이 되거나, 제한 시간이 다하면 게임 오버입니다.
중점 확인 사항화면 이동, 안내 문구, 도구 선택, 접촉·중화, 결과 화면·재시작이 정상인지 확인합니다.

이 문서는 게임을 처음 접하는 분도 기능을 확인할 수 있도록 구성되었습니다. 플레이 실력보다, 화면과 기능이 이해하기 쉬운지 확인하는 것이 중요합니다.

실행 시 .exe와 같은 폴더의 _Data 폴더를 함께 두세요. exe만 따로 옮기면 실행되지 않을 수 있습니다.

2. 게임 진행 순서

1받은 .exe를 실행합니다. 스플래시 → 타이틀 화면이 나옵니다.
2타이틀에서 시작하기를 누릅니다. (처음이면 인트로 스토리 → 로딩 화면을 거칩니다.)
3게임 화면에 들어가면 오른쪽으로 이동하세요 안내가 나옵니다. 안내가 사라진 뒤 이동이 시작됩니다.
4잠시 이동하면 [경고] ○○ 오염물질 발견이 뜨고 오염원이 등장합니다. Z/X로 도구를 고릅니다.
5오염원에 닿아 중화합니다. 구역의 오염원을 모두 없애면 다시 이동해 다음 구역으로 넘어갑니다.
6스테이지를 클리어하거나 방호복이 0이 되면 결과 화면이 나옵니다. 다시 시작이 되는지도 확인합니다.

3. 화면에서 확인할 요소

방호복 HP (오른쪽 위)오염원에 닿으면 줄어듭니다. 0이 되면 게임 오버입니다.
남은 시간제한 시간이 지나면 게임 오버입니다.
중화 도구 창 (왼쪽 아래)Z/X로 도구를 바꿉니다. 고른 칸이 더 밝게 보입니다.
안내 팝업 (GuideTxt)이동·도구 선택·틀린 도구 등 상황별 안내 문구가 뜹니다.
K / I 키조작 설명·아이템 설명 창을 열고 닫습니다.
회복 인벤 (오른쪽 아래)오염원 제거 후 떨어진 아이템. C/V로 고르고 Space로 사용합니다.

4. 주요 QA 항목 10가지

QA-01. 게임 실행 확인
확인 방법

배포받은 실행 파일(Hazmat Rush.exe)을 더블클릭하고, 첫 화면(스플래시 또는 타이틀)이 정상적으로 표시되는지 확인합니다.

정상 기준

게임이 종료되지 않고 첫 화면이 표시되며, 타이틀에서 시작 버튼을 클릭할 수 있습니다.

문제 기준

게임이 실행되지 않거나, 화면이 멈추거나, 시작 버튼이 반응하지 않습니다.

QA-02. 화면 이동 흐름 확인
확인 방법

타이틀에서 시작하기를 누른 뒤, 인트로·로딩을 거쳐 실제 게임 화면(캐릭터가 보이는 화면)까지 진행해 봅니다. 중간에 「다음에 무엇을 눌러야 하는지」「현재 화면이 어떤 역할인지」가 자연스럽게 이해되는지 확인합니다.

정상 기준

처음 플레이하는 사람도 큰 설명 없이 게임 화면까지 도달할 수 있고, 캐릭터·방호복 막대·시간 등 HUD가 보입니다.

문제 기준

중간에 다음 버튼을 찾기 어렵거나, 게임 화면까지 진행하지 못하거나, 화면이 검은 채로 멈춥니다.

QA-03. 시작 안내 및 이동 시작
확인 방법

게임 화면에 들어가면 오른쪽으로 이동하세요 안내가 뜹니다. 안내가 떠 있는 동안과 사라진 뒤 각각 ←→ 키로 이동해 봅니다.

정상 기준

안내가 떠 있을 때는 이동·시간이 멈추고, 안내가 사라진 뒤 이동·시간·배경 스크롤이 시작됩니다. K/I로 도움말 창도 열 수 있습니다.

문제 기준

안내 없이 갑자기 시작되거나, 안내가 사라져도 이동이 안 되거나, 언제 움직여도 되는지 알기 어렵습니다.

QA-04. 오염원 경고 및 등장
확인 방법

첫 안내가 끝난 뒤 오른쪽으로 2~3초 걸어갑니다. [경고] ○○ 오염물질 발견 경고가 뜨고, 이어서 오염원이 서서히 나타나는지 확인합니다.

정상 기준

경고 → 오염원 등장 연출이 자연스럽고, 등장 후 다시 이동할 수 있으며, 이전보다 오른쪽으로 더 멀리 갈 수 있습니다.

문제 기준

경고나 오염원이 나오지 않거나, 등장 후에도 이동이 안 되거나, 게임 진행이 멈춥니다.

QA-05. 중화 도구 선택 (Z / X)
확인 방법

경고 직후 Z키(왼쪽)/X키(오른쪽)로 대응 아이템을 골라주세요 안내가 보이는지 확인하고, Z/X 키로 왼쪽 아래 도구 창의 중화 도구를 바꿔 봅니다.

정상 기준

Z/X로 도구가 바로 바뀌고, 지금 고른 도구 칸이 다른 칸보다 밝게 보입니다.

문제 기준

키를 눌러도 도구가 바뀌지 않거나, 어떤 도구가 선택됐는지 구분하기 어렵습니다.

QA-06. 오염원 접촉 및 방호복 감소
확인 방법

오염원에 닿은 채로 잠시 기다립니다. 방호복 HP(오른쪽 위)와 오염원 체력 막대가 보이는지, 닿는 동안 방호복이 줄어드는지 확인합니다. 오염원에서 떨어져 보세요.

정상 기준

접촉 중 막대가 유지되고 방호복이 감소합니다. 떨어지면 막대가 사라지고 오염원 체력이 처음으로 돌아갑니다.

문제 기준

닿아도 방호복이 안 줄거나, 떨어져도 체력이 초기화되지 않거나, 막대가 보이지 않습니다.

QA-07. 맞는/틀린 도구 판정
확인 방법

먼저 틀린 도구를 고른 뒤 오염원에 닿아 보세요. 그다음 맞는 도구로 바꿔 닿아 보세요. (1-1 첫 구역은 가스 2마리 — 가스밸브가 맞는 도구입니다.)

정상 기준

틀리면 방호복만 줄고 오염원 체력·파란 중화 이펙트는 없습니다. 맞으면 오염원 체력도 줄고 파란 중화 이펙트가 나옵니다. (가스는 QA-08 참고)

문제 기준

틀린 도구인데도 오염원이 줄거나, 맞는 도구인데 중화가 안 되거나, 맞고 틀린 구분이 전혀 안 됩니다.

QA-08. 가스(D) 밸브 연출
확인 방법

가스 오염원에 가스밸브를 고른 뒤 닿아 보세요. 캐릭터가 밸브를 돌리는 연출과 효과음이 나오는지, 파란 중화 이펙트는 없는지 확인합니다.

정상 기준

가스밸브 + 가스 접촉 시 밸브 돌리기 애니·효과음이 나오고, 일반 파란 중화 이펙트는 나오지 않습니다. 오염원 체력은 줄어듭니다.

문제 기준

밸브 연출이 없거나, 가스에도 파란 이펙트가 나오거나, 가스밸브로도 중화가 안 됩니다.

QA-09. 클리어·게임오버 결과 화면
확인 방법

클리어: 스테이지를 끝까지 진행하거나, 테스트 빌드에 F1이 있다면 F1으로 클리어 연출을 확인합니다.
게임오버: 방호복이 0이 되도록 일부러 오염원에 오래 닿아 있거나, F2로 확인합니다. 결과 패널이 나오는지 봅니다.

정상 기준

클리어/사망 연출 후 약 2초 뒤 결과 패널(클리어 또는 게임오버)이 자연스럽게 표시됩니다. 연출과 패널이 동시에 겹치지 않습니다.

문제 기준

조건을 만족해도 결과 화면이 안 나오거나, 화면이 멈추거나, 패널이 연출 전에 바로 뜹니다.

QA-10. 다시 시작 기능
확인 방법

클리어 또는 게임오버 결과 화면에서 다시 시작(또는 재시작) 버튼을 눌러, 새 게임처럼 정상적으로 시작되는지 확인합니다.

정상 기준

다시 시작 후 이전 오염원·이펙트·UI 상태가 남지 않고, 처음 안내부터 정상적으로 진행됩니다.

문제 기준

이전 오염원이나 이펙트가 남거나, 버튼이 반응하지 않거나, 게임 속도·사운드가 비정상적입니다.

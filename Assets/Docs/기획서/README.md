# 사전 기획서 (중간 팀프로젝트 제출)

| 파일 | 용도 |
|------|------|
| `mid_team_project_submission.html` | 강사 제출 양식 · **열 때 06-15 JSON 자동 반영** · PDF/Word/JSON 저장 |
| `기획서_진영(개인)_2026-06-15.json` | 기획 내용 원본 (최신) · HTML과 동기화 |
| `기획서_진영(개인)_2026-06-14.json` | 이전 스냅샷 (프로젝트 현행화 버전) |

## 사용 방법

1. **`mid_team_project_submission.html`** 을 Chrome/Edge에서 연다 (Desktop 동일 파일도 연결됨).
2. **`기획서_진영(개인)_2026-06-15.json`** 이 HTML에 내장되어 **열자마자 채워짐**.
3. **PDF로 내보내기** → `사전기획서_진영(개인)_Hazmat Rush_YYYY-MM-DD.pdf`
4. HTML에서 수정 후 **저장** → JSON 다시 내보내 두 파일 맞춤.

## Desktop 파일

- `mid_team_project_submission_2026_6_1.html` + `기획서_진영(개인)_2026-06-15.json` — repo와 **동일 연결 상태**로 복사해 둠.

# 사전 기획서 (중간 팀프로젝트 제출)

| 파일 | 용도 |
|------|------|
| `mid_team_project_submission.html` | 강사 제출 양식 · 브라우저에서 열어 PDF/Word/JSON 저장 |
| `기획서_진영(개인)_2026-06-14.json` | 기획 내용 원본 · HTML과 동기화 |

## 사용 방법

1. **`mid_team_project_submission.html`** 을 Chrome/Edge에서 더블클릭해 연다.
2. 같은 폴더의 JSON이 HTML에 내장되어 있어 **열자마자 내용이 채워진다.**
3. 내용 확인 후 상단 **「PDF로 내보내기」** 로 `사전기획서_진영(개인)_Hazmat Rush_YYYY-MM-DD.pdf` 저장.
4. HTML에서 수정했다면 **「저장」** 으로 JSON을 다시 내보내 두 파일을 맞춘다.

## JSON만 수동으로 불러올 때

자동 반영이 안 되면 **「JSON 불러오기」** → `기획서_진영(개인)_2026-06-14.json` 선택.

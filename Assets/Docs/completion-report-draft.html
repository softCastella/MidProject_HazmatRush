발표 멘트 (도입 30초 예시)

안녕하세요. 오늘 발표 주제는 2D 오염 대응 시뮬레이션 게임입니다. 플레이어는 현장처럼 이동하다 오염원을 만나고, 물질 종류에 맞는 장비를 고른 뒤 제한 시간 안에 중화하는 게임입니다. 잠시 후 직접 플레이 화면도 보여 드리겠습니다.

3. 프로젝트 요약

MidProject는 2D 횡스크롤에서 화학·유해 오염물질을 탐지하고, 오염원 유형에 맞는 대응 아이템으로만 중화하는 Unity 게임입니다.

방호복 HP와 제한 시간을 지키며 스테이지별 오염원을 모두 처리하면 클리어합니다. 틀린 아이템으로 접촉하면 방호복만 줄고, 오염원은 줄지 않습니다.

한 줄 플레이 루프: 이동 → 경고 → 아이템 선택(Z) → 접촉 중화 → 맵 진행 또는 클리어

4. 기획 배경

왜 이 게임인가

  • 화학·유해 물질 사고 현장에서는 물질 종류 파악 → 맞는 대응이 중요합니다.
  • 실제 훈련은 비용·안전 부담이 크므로, 게임으로 반복 연습할 수 있는 환경을 목표로 했습니다.
  • 「틀린 도구를 쓰면 피해만 커진다」는 규칙을 플레이로 체험하게 하고 싶었습니다.

대상·기대 효과

  • 대상: 게임/Unity 학습자, 안전 교육 콘텐츠 시연용
  • 효과: 오염원 타입(A/B/C)과 대응 수단(중화제·패드 등)의 관계를 짧은 플레이로 기억

5. 게임 규칙·컨셉

플레이어가 할 일

  • 가이드 종료 후 좌우 이동, 일정 시간 이동 시 오염원 경고
  • Z키로 대응 아이템 선택 후 접촉해 중화
  • 스테이지 오염원을 시간 내 전부 처리 → 클리어
  • 방호복 0 또는 시간 초과 → 게임 오버

오염원·아이템 (발표 슬라이드용)

8. 어려웠던 점·배운 점

발표에서는 아래 3가지만 말해도 충분합니다. (코드 이름은 슬라이드에 작게만)

어려움해결·배운 것
접촉할 때 방호복·오염원 HP가 동시에 변함 접촉 유지 중에만 데미지를 주고, 맞는 아이템일 때만 오염원 HP가 줄도록 순서를 정리함. Unity 트리거(Trigger) 이해.
씬이 여러 개(타이틀·로딩·게임)일 때 진행이 끊김 로딩 씬에서 게임 씬을 미리 읽고, 이어할 스테이지 번호를 넘기는 방식으로 연결. JSON으로 스테이지 데이터 분리.
경고·페이드·맵 이동이 겹치면 버그 코루틴(시간 지연)과 일시정지가 충돌하지 않게, 맵 전환 중에는 pause를 막고 대기 시간은 실시간 기준으로 처리.

Unity·C#에서 배운 것 (소갬용)

  • 2D 이동(Rigidbody2D), UI(TextMeshPro), Animator 상태 전환
  • 씬 전환, 싱글톤으로 BGM 유지, JSON 파일 읽기
  • 기능을 나누는 방법 (플레이어 / 오염원 / 게임 진행 / UI)

10. 시연 체크리스트

발표 전날·당일 Play로 한 번씩 확인하세요.

  1. TitleScene — 저장 없으면 시작하기만
  2. 1스테이지 클리어 → 타이틀 — 이어하기 버튼 보임
  3. 이어하기 → 저장된 스테이지부터 시작
  4. 경고 → Z키 안내 → 오염원 등장·팝업
  5. 정답 아이템: 오염원 HP 감소 / 오답: 방호복만 감소
  6. (시간 되면) 중간 오염원 후 맵 끝 이동·페이드
  7. 마지막 오염원 클리어 → 클리어 패널

시연 중 F1/F2 디버그 키는 교수님 앞에서 쓰지 않는 것을 권장합니다.

# Docs 하네스 — 문서 종류·취합·이름 규칙

`Assets/Docs/` 아래 **Bug**·**회의록** 작성·수정 시 AI·작성자가 따르는 규칙입니다.

---

## 1. 폴더별 작성 내용 (하네스)

### `Docs/Bug/` — 버그·수정 기록 (`-fixes.md`)

**무엇을 쓰는가:** 증상 → 원인 → 시도 → **최종 해결** → 변경 파일 → Play 체크리스트.

| 섹션 | 내용 |
|------|------|
| 상단 메타 | 최초작성·수정·차수, 관련 회의록 링크, 선행 Bug |
| 증상·원인 | 재현 조건, Console·Inspector 단서 |
| 시도·해결 | 실패한 1차 시도가 있으면 명시 후 채택안 |
| 파일 목록 | 변경한 `.cs`·씬·설정 |
| 체크리스트 | `- [ ]` 실플레이 확인 항목 |
| **쓰지 않음** | 장기 아키텍처·PR 로드맵·팀 정책 (→ 회의록) |

### `Docs/회의록/` — 합의·설계·정책 (`-합의.md`)

**무엇을 쓰는가:** 배경 → **합의 규칙** → 구현 상태 → 금지 사항 → QA·체크리스트.

| 섹션 | 내용 |
|------|------|
| 상단 메타 | 최초작성·수정·차수, 주제, 관련 스크립트, Bug 링크 |
| 배경 | 왜 논의했는지, 선행 문서 |
| 합의 본문 | 동작 규칙·표·흐름도 (코드보다 **의도**) |
| 구현 상태 | ✅ / 🟡 / 보류 |
| 금지·주의 | 회귀 방지 (예: `timeScale=0` 재도입 금지) |
| 변경 이력 | 세션별 한 줄 요약 |
| **쓰지 않음** | 증상만 나열·파일 diff 나열 (→ Bug) |

### Bug ↔ 회의록

- **역할 분리:** 회의록 = 합의·정책 (`회의록/`). Bug = 증상·수정 (`Bug/`).
- **회의록 작성만 요청**되면 `Bug/`에 파일 **만들지 않음**. Bug는 버그·수정 기록을 **별도 요청**할 때만.
- 둘 다 있을 때만 상단 메타에 상호 링크.

## 2. 당일 취합 규칙

**같은 날짜**에 Bug 또는 회의록을 여러 번 쓰면, **문서 종류별로 그날 마지막 파일 하나**에 모읍니다.

| 규칙 | 내용 |
|------|------|
| 대상 | `Bug/` 와 `회의록/` **각각 독립** (Bug끼리, 회의록끼리만 취합) |
| 취합 위치 | 그날 해당 종류의 **가장 늦은 세션 문서** (없으면 새로 생성) |
| 본문 구조 | `## 세션 오후 HH:mm — {주제}` 로 구간 분리 |
| 이전 파일 | 내용 이전 후 **삭제** (링크는 취합본으로 갱신) |
| 차수 | 취합·대폭 수정 시 **수정 차수** +1 (`1차` → `2차` …) |
| 파일명 | 아래 §3 형식으로 **갱신** (최초작성 시각은 그날 **첫 세션** 유지) |

**예 (2026-06-09):** 오후 12:27 · 13:16 · 14:00 회의록 3세션 → `회의록/` 취합본 1건. Bug 취합은 **Bug 기록을 쓸 때만** 동일 규칙.

---

## 3. 파일명 형식

```text
{날짜}-{최초작성시각}-{이름}-{수정시각}-{N}차-{접미사}.md
```

| 필드 | 형식 | 설명 |
|------|------|------|
| **날짜** | `YYYY-MM-DD` | 작업일 |
| **최초작성시각** | `오전`/`오후` + `HHmm` | 그날 **첫** 세션 시각 (취합 후에도 유지) |
| **이름** | `짧은-제목` (한글·영문, 하이픈) | 하루 취합 시 `0609-일일` 등 대표 제목 |
| **수정시각** | `오전`/`오후` + `HHmm` | **마지막** 반영·취합 시각 |
| **수정 차수** | `1차`, `2차`, … | 당일 취합 또는 동일 파일 대폭 수정마다 증가 |
| **접미사** | `fixes` / `합의` | Bug는 `-fixes.md`, 회의록은 `-합의.md` |

### 예시

```text
2026-06-09-오후1227-0609-일일-오후1400-1차-fixes.md
2026-06-09-오후1227-0609-일일-오후1400-1차-합의.md
```

- 단일 세션만 있고 당일 추가 없음: 최초 = 수정 시각, 차수 `1차`.
- 전날 작업·오늘 소급·시각 모름: 기존처럼 `YYYY-MM-DD-시각미상-{이름}-…` (최초작성 시각만 `시각미상`).

## 4. 문서 안 제목 (H1)·메타

### H1

```markdown
# Bug — YYYY-MM-DD — {이름} (최초 오후 HH:mm · 수정 오후 HH:mm · N차)
# 회의록 — YYYY-MM-DD — {이름} (최초 오후 HH:mm · 수정 오후 HH:mm · N차)
```

### 상단 메타 표

```markdown
| **최초작성** | YYYY-MM-DD · 오후 12:27 |
| **수정** | YYYY-MM-DD · 오후 14:00 |
| **수정 차수** | 1차 |
| **관련 합의** / **버그 기록** | 상대 문서 링크 |
```

- `시각 미상` 문서: 최초작성 행만 `YYYY-MM-DD · 시각 미상`.

---

## 5. 시각 정하기 (AI·작성자)

| 상황 | 최초작성 시각 | 수정 시각 |
|------|---------------|-----------|
| **오늘** 작업·**오늘** 문서화 | 현재 시각 (`오전`/`오후` + `HHmm`) | 반영·취합 시각 |
| **전날** 작업·**오늘** 소급 | `시각미상` (작업일 날짜) | 오늘 작성 시각 |
| **당일 추가 세션** | **변경 없음** (첫 세션 유지) | 새 세션 시각, 차수 +1 |

- 오늘 작업 문서에 `시각미상` **금지**.
- 나중에 회의 시각을 알면 `시각미상` 문서만 파일명·메타 갱신.

## 6. 기타 폴더 · 금지

| 폴더 | 용도 |
|------|------|
| `Docs/Bug/` | §1 Bug **만** (`-fixes.md`) |
| `Docs/회의록/` | §1 회의록 **만** (`-합의.md`) |
| `Docs/` 루트 | QA HTML, Git workflow 등 |

| 금지 | |
|------|--|
| `Bug/`에 회의록·합의 본문 | → `회의록/` |
| `회의록/`에 증상·diff 나열 | → `Bug/` |
| QA HTML에 합의·정책 본문 이식 | 링크만, TC·검증 항목만 |
| `qa-*.html`을 회의록/Bug **대체**로 쓰기 | 당일 취합은 `.md`만 |

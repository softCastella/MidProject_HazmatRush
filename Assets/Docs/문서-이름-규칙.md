# Docs 문서 파일·제목 이름 규칙

`Assets/Docs/` 아래 새 문서를 만들 때 **날짜만** 쓰지 말고 **오전/오후·시각**을 파일명과 제목에 넣습니다.

---

## 시각 정하기 (AI·작성자 공통)

| 상황 | 파일명 시각 | **작성** 메타 |
|------|-------------|----------------|
| **오늘** 작업을 **오늘** 문서화 | **현재 작성 시각** (`오전`/`오후` + `HHmm`) | `YYYY-MM-DD · 오전/오후 HH:mm` |
| **전날(이전 날)** 작업을 **오늘** 문서화 | `시각미상` | `YYYY-MM-DD · 시각 미상` (날짜는 **작업일**) |

- 오늘 작업 문서: 터미널 등으로 **작성 당시 시각** 확인 후 넣기. `시각미상` 쓰지 않음.
- 전날 분 소급 정리: 작업이 일어난 **날짜**는 그대로, 시각만 `시각미상`.
- 나중에 회의 시각을 알게 되면 전날 문서만 파일명·**작성** 행을 `오전/오후 HHmm`으로 고침.

**예 (오늘이 2026-06-09일 때)**

| 작업일 | 작성일 | 파일명 예 |
|--------|--------|-----------|
| 2026-06-09 | 2026-06-09 | `2026-06-09-오후1227-경고-맵이동-클리어-회복-fixes.md` |
| 2026-06-08 | 2026-06-09 | `2026-06-08-시각미상-회복아이템-아크드랍-fixes.md` |

## 파일명 형식

```text
YYYY-MM-DD-{오전|오후}{HHmm}-{짧은-제목}.md
```

| 예시 | 의미 |
|------|------|
| `2026-06-05-오후1530-플레이어-오염원-로직-검토.md` | 2026-06-05 오후 3:30 |
| `2026-06-04-오전1030-gameplay-fixes.md` | 2026-06-04 오전 10:30 |

- `HHmm` = 24시간제 4자리 (1530 = 15:30)
- **오전** = 00:00~11:59, **오후** = 12:00~23:59 (12시는 오후1200)

### 시각 미상 (전날 작업을 오늘 소급 작성할 때)

```text
YYYY-MM-DD-시각미상-{짧은-제목}.md
```

- **용도:** 작업일 ≠ 작성일이고, 당시 시각을 모를 때만.
- **금지:** 오늘 작업·오늘 작성 문서에 `시각미상` 사용.
- 나중에 시각을 알게 되면 파일명·문서 상단 **작성** 행을 고쳐 주세요.

---

## 문서 안 제목 (H1) 형식

```markdown
# {종류} — YYYY-MM-DD {오전|오후} HH:mm — {제목}
```

시각 미상:

```markdown
# 회의록 — 2026-06-05 시각미상 — 플레이어·오염원 로직 검토
```

표 상단 메타:

```markdown
| **작성** | 2026-06-05 · 오후 15:30 |
| **작성** | 2026-06-05 · 시각 미상 |
```

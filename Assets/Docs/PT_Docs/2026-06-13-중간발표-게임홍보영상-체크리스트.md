## 1. 컨셉 (선생님 안내)

> 데모 영상 = **플레이 녹화본**이 아니라 **게임 홍보영상(트레일러)** 로 만든다.

| 구분 | ❌ 아닌 것 | ✅ 홍보영상 |
|------|-----------|-------------|
| 톤 | 조작 설명·튜토리얼 | **「이 게임이 뭐고, 왜 재밌는지」** 한눈에 |
| 편집 | 한 컷 긴 Play | **짧은 컷** · BGM · (선택) 타이틀·카피 |
| 내용 | UI·가이드 전부 노출 | **가장 멋진 장면**만 골라 담기 |
| 참고 (타 팀) | — | 펭귄 레스토랑·Pink Demon·Galaxy Ball **「홍보 영상」** 슬라이드 |

발표 슬라이드 제목 예: **「게임 홍보 영상」** 또는 **「HazmatRush Trailer (~30s)」**

---

## 2. 홍보 메시지 (30초 안에 전달할 한 줄)

**게임:** 2D 횡스크롤 · 방호복 유지 · **맞는 도구로** 오염원 중화

**홍보 카피 후보 (1개만 영상에):**

- 「위험한 현장, 맞는 도구만이 답이다」
- 「방호복을 지키며, 오염을 중화하라 — HazmatRush」
- 「HazmatRush — 해즈멧러쉬」

---

## 3. 권장 구성 (~30초)

| 순서 | 장면 | 길이 | 홍보 역할 |
|------|------|------|-----------|
| 1 | **타이틀 / 로고** (또는 스플래시 1컷) | 2~3초 | 브랜딩 |
| 2 | 플레이어 이동 + **경고** UI | 4~5초 | 긴장·장르 |
| 3 | 오염원 등장 → Z/X → **정답** + **중화 VFX** | 10~12초 | **핵심 재미** |
| 4 | (선택) 가스 **밸브** 또는 방호복 HP 긴장 1컷 | 4~5초 | 차별점 |
| 5 | **클리어·별점** 또는 타이틀 재등장 + 카피 | 4~5초 | 마무리 |

**합계:** ~27~30초

App 전체·로딩·인트로·회복 인벤 상세는 **넣지 않음** (홍보에선 잘리는 구간).

## 4. 촬영·소스

| 항목 | 권장 |
|------|------|
| Unity | `GameScene` Play (가장 안정) |
| 해상도 | 1920×1080 |
| 녹화 | OBS / Unity Recorder / Win+G |
| BGM | 게임 BGM 1곡 또는 짧은 SUNO/무료 트랙 (저작권 확인) |
| 자막 | 카피 1줄 + (선택) 「PC v1.0」 |

**촬영 전:** 가이드 스킵 가능 구간·경고~등장까지 **리허설 1회** → 가장 멋진 1판만 녹화.

| 항목 | 내용 |
|------|------|
| **현상** | 고속 이동·가스 접촉 시 **방호복·오염원 HP가 중간에 멈춤** · 접촉 중인데 데미지·VFX **끊김** (가스 HP ~17에서 멈춤 등) |

| **인사이트** | 2D 트리거 — **「막기」와 「접촉 판정」을 분리**해야 고속 이동에서도 HP가 안 끊긴다 |

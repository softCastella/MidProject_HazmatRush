## 1. 발표에서 가장 쓸 말 (한 줄)

> **PC v1.0** = **6씬 플로우**(App→Game) + **한 판 게임 루프**(접촉→회복→클리어/게임오버→결과)

**「풀 구성」**은 범위가 애매하므로 발표에서는 **위 두 가지를 나눠 말하거나**, 통칭만 **PC v1.0**으로 부릅니다.

## 2. 계층 (큰 것 → 작은 것)

```text
PC v1.0  (중간 발표 결과물 통칭)
├── 6씬 플로우  … App → Splash → Title → Intro → Loading → Game
└── 한 판 게임 루프  … Game 안: 가이드 → 이동 → 경고 → Z/X → 접촉 → 회복 → 클리어/GO → 결과 패널
```

| 용어 | 무엇을 가리키나 | HazmatRush 예 |
|------|-----------------|---------------|
| **PC v1.0** | 위 **둘 다** 갖춘, QA 받을 수 있는 **플레이 가능 빌드** | 외부 QA 7명 · `VersionText` v1.0 |
| **6씬 플로우** | 앱 켜기부터 **본편(Game) 진입**까지 씬이 빠짐없이 연결 | AppScene → … → GameScene |
| **한 판 게임 루프** | GameScene에서 **한 스테이지를 처음~끝** | 접촉·회복·클리어·별·패널 |
| **스테이지 JSON 3개** | **콘텐츠 양** (맵·오염원 구성) | `stage_data.json` 1-1 ~ 1-3 |

**v1.0 ≠ 모든 스테이지·튜토리얼·출시 완료.**  
양은 Next(1차 튜토리얼, 2차 게임성)에서 늘리는 부분입니다.

## 3. App~Game 6씬 — 뭐라 부르나 (비교표)

**App → Splash → Title → Intro → Loading → Game** 까지 **6씬만** 말할 때 쓸 수 있는 용어입니다.

| 용어 | 뜻 | App~Game만? |
|------|-----|-------------|
| **씬 플로우 / Scene Flow** | 씬 **전환 순서**가 완성됨 | ✅ **이거** |
| **앱 진입 ~ 본편 흐름** | 비개발 청중용 **쉬운 말** | ✅ |
| **End-to-End (E2E) 플로우** | **처음부터 끝까지** 한 줄로 이어짐 | ✅ (조금 기술적) |
| **메타 플로우** | **본편(Game) 전** — Splash·Title·Intro·Loading | △ Game **제외**할 때가 많음 |
| **버티컬 슬라이스 (Vertical Slice)** | “얇지만 **한 줄기** 완성” (씬 + 한 판 플레이) | △ 씬만이 아니라 **루프까지** 포함할 때 |

> **App~Game 6씬만** 말할 때는 **버티컬 슬라이스**보다 **씬 플로우**가 더 정확합니다.

### 같이 쓰는 말

| 용어 | 설명 |
|------|------|
| **씬 흐름** | 씬 플로우와 **동일** (슬3 PPT 표 헤더) |
| **GameScene 직접 Play** | 개발·테스트용 (App 설정 생략) · “6씬 완성”과 **구분** |

### 6씬 목록

`App` → `Splash` → `Title` → `Intro` → `Loading` → `Game`  
(이어하기 시 Intro 생략)

### Issue 3 · 접촉 끊김 (Q&A 예비)

| 용어 | 설명 |
|------|------|
| **접촉 끊김** | 겹쳐 있는데 HP·데미지가 **중간에 멈춤** |
| **ClampPassThrough** | Player — 오염원 **통과 방지** · 트리거 **밖**에서 멈추면 Stay 끊김 |

| **막기 vs 접촉 판정 분리** | 이동 clamp와 데미지 경로 **역할 분리** (해결 요지) |

## 9. 질문 예상 · 짧은 답

**Q. 프로토타입 아닌가요?**  
A. 코어 검증으로 **시작**했지만, 지금은 App~Game **6씬**과 **한 판 클리어/게임오버**까지 되는 **PC v1.0**입니다.

**Q. App~Game 다 있는 걸 뭐라 하나요?**  
A. **6씬 플로우**(씬 플로우) 완성입니다.

**Q. 아직 더 만들 것은?**  
A. **Next** — 1차 튜토리얼, 2차 스테이지·게임성. v1.0은 **한 판 루프**까지입니다.

**Q. OnTrigger 문제가 뭐였나요?**  
A. 이동 **막기**와 **접촉 판정**이 엇갈려 HP가 끊겼고, 예전엔 **LateUpdate 우회**로 경로가 둘이었습니다. **단일 경로**로 맞췄습니다.

## 1. 3단계 요약

```text
① PT_Docs 슬라이드별 텍스트 원고 작성 (캡처 없이)
      ↓
② Genspark AI Slides — 아웃라인 확인 후 전체 생성
      ↓
③ PPTX/PDF 내보내기 → 캡처·홍보영상·Issue Before/After만 덮어쓰기
```

| 단계 | 문서·도구 | 목적 |
|------|-----------|------|
| ① | `슬라이드별-문구.md` | 사실·분량 고정 (Genspark 입력용) |
| ② | Genspark | 레이아웃·디자인 자동화 |
| ③ | Unity 캡처 · mp4 | 슬4·5·7·9 시각 자료만 교체 |

**주의:** Genspark는 디자인에 강하고, **게임 수치·규칙은 README와 어긋날 수 있음**. 원고에 없는 내용은 생성 후 반드시 [README.md](../../README.md)와 대조한다.

## 2. 슬라이드 원고 작성 규칙

| 규칙 | 이유 |
|------|------|
| 슬라이드당 **제목 1줄 + bullet 3~5개** | Genspark·발표 화면 모두 가독성 |
| 표는 markdown 표 그대로 | 슬5 오염원·도구 |
| 이미지 자리는 `[캡처: …]` **괄호 메모**만 | 나중에 교체 |
| 슬4는 **「영상 삽입」** 명시 | 큰 플레이스홀더 유도 |
| **발표 멘트**는 슬라이드 본문과 분리 | 화면 지저분함 방지 |

목차 문서 = **뼈대** · 슬라이드별 문구 = **Genspark 입력용** · 이 문서 = **절차**.

## 2.1 계정 · Cursor와의 관계

| 항목 | 설명 |
|------|------|
| **Genspark 계정** | Cursor·GitHub·Notion과 **별도** — 과정에서 받은 계정 그대로 사용 |
| **연동 필요** | ❌ Cursor와 Genspark 계정을 맞출 필요 없음 |
| **작업 흐름** | Cursor `PT_Docs` 원고 작성 → **복사/Import** → Genspark 웹에서 생성 → export |

---

## 2.2 Cursor MCP vs Genspark

| 도구 | MCP | PPT |
|------|-----|-----|
| **Cursor** (지금) | Notion · Figma 등 — **Genspark MCP 없음** | 원고·Bug·README 작성 |
| **Genspark** | **클라이언트** — 채팅 아래 Tools → 외부 MCP 추가 가능 (데이터 연동용) | AI Slides로 PPT 생성 |
| **대안** | Alai · deck-builder 등 **PPT 전용 MCP** (별도 가입·API 키) | Cursor에서 바로 `.pptx` — Genspark와 별도 선택 |

**이번 중간 발표:** Genspark 웹 + `PT_Docs` 수동 복붙이 가장 단순. MCP 자동 연동은 필수 아님.

## 3. Genspark 입력 방법

### 방법 A — Guide 모드 + 구조 고정 (추천)

1. [Genspark AI Slides](https://www.genspark.ai/tools/ai-presentation-maker) 접속
2. 아래 **첫 프롬프트** + [슬라이드별-문구.md](2026-06-13-중간발표-슬라이드별-문구.md) **「Genspark 붙여넣기 블록」** 전체 붙여넣기
3. **아웃라인만** 먼저 생성 → **12장**·순서 확인
4. OK 후 전체 생성 → 슬라이드별 문구 수정
5. **View & Export** → PPTX 또는 PDF

### 방법 B — 파일 Import

`슬라이드별-문구.md`를 Word/PDF로 저장 → Genspark **Import File**  
(마크다운 업로드가 불안정할 때 사용)

## 1. 스테이지 BGM이 항상 0번만 재생

| 항목 | 내용 |
|------|------|
| **증상** | `stage_data.json` `bgmIndex` 1·2 스테이지도 첫 곡과 동일하게 들림. |
| **원인 1** | `AudioManager.OnSceneLoaded` / `Start`가 `GameScene`마다 `PlayGameBGM()` → `PlayStageBgm(0)` 호출. |
| **원인 2** | Splash 등 중복 `AudioManager`가 먼저 뜨면 `stageBgmClips` 미병합 → `PlayStageBgm(n)`이 `gameBGM`(0번과 동일)으로 fallback. |
| **해결** | `PlayBGMForScene("GameScene")`에서 BGM 자동 재생 제거. `CopyStageBgmClipsIfNeeded` 추가. `StageManager.LoadStage`가 `bgmIndex` 재생. |
| **파일** | `AudioManager.cs`, `StageManager.cs`(기존 호출 유지) |

### Play 체크리스트

- [ ] `AppScene` Play → 1-2 클리어 후 BGM 변경
- [ ] `GameScene` 단독 Play → 스테이지별 `bgmIndex` 반영
- [ ] DontDestroyOnLoad `AudioManager` · `Stage Bgm Clips` 3개 유지

## 2. 가이드 팝업 배경 미표시 · bg0/bg1 이중 표시

| 항목 | 내용 |
|------|------|
| **증상** | 안내·경고 문구만 보이고 팝업 이미지 없음. 긴 문구에서 바깥·안쪽 팝업 2겹. |
| **원인 1** | `bg0`/`bg1`/`Bg`가 씬에서 비활성, 코드는 `guide_text`/`WarningMsg`만 활성화. |
| **원인 2** | `bg1` 루트 Image + 자식 `bg (1~3)`(동일 스프라이트)을 전부 ON → 이중·삼중 테두리. |
| **원인 3** | 팝업 ON/OFF 경로가 여러 함수에 분산. |
| **해결** | `WarningTxt` — `Bg`·`WarningLabel`·`WarningMsg` 동시 제어. `GuideTxt` — `ApplyPopup(Hidden/Short/Long)` 단일화, `bg0`/`bg1` 상호 배타, 자식 `bg (1~3)` 항상 OFF. Inspector에 `popupShortRoot`/`popupLongRoot` 연결. |
| **파일** | `GuideTxt.cs`, `WarningTxt.cs`, `GameScene.unity` |

## 4. 가스(D) 구간 사망 후 오염원 HP바 잔류 — 1차 해결

| 항목 | 내용 |
|------|------|
| **증상** | 밸브 씬에서 방호복 0 사망 후 `pollutantHpSlider`가 화면에 남음. |
| **원인** | `ApplyPollutantDamage` → `StartDeathSequence` 직후에도 `UpdatePollutantHpBar()` 실행. `FixedUpdate`가 사망 시 `HideBars` 없이 return. |
| **해결** | `BeginPlayerDeathSequence`에서 `HidePollutantHpBar()`. `ApplyPlayerContactDamage` 사망 직후 `HideBars`. `FixedUpdate` 사망·`GameEnded` 시 `HideBars`. |
| **파일** | `Pollutant.cs`, `PollutantManager.cs`, `GameManager.cs` |

### Play 체크리스트

- [ ] 가스 접촉 중 방호복 0 → Die 연출 중 HP바 숨김
- [ ] A~C 접촉 중 사망도 동일

## 5. 【미해결】가스 사망 시 밸브 애니 루프

| 항목 | 내용 |
|------|------|
| **증상** | 밸브(가스) 구간에서 사망 시 **`밸브 → Die(약 1초) → 밸브 → 사라짐`** 이 반복됨. HP바는 1차 수정 후 숨겨짐. |
| **재현** | 1-1 등 가스(D) 오염원 · 가스밸브 정답 접촉 중 방호복 0까지 대기 → 사망 연출 관찰. |
| **원인 후보** | `StartDeathSequence`에서 `valveAnimActive=false` 후 `Pollutant.ApplyPlayerContactDamage` / 트리거가 `SetValveAnimActive(true)` 재호출. `gameOverPending` 중 밸브 ON 금지 미적용. |
| **시도** | (없음 — 후속 세션에서 수정 예정) |
| **다음 수정 방향** | `Player.IsDead` 또는 `GameManager.IsGameOverPending`이면 `SetValveAnimActive(false)`만 허용·true 금지. `Pollutant` 사망 후 접촉 처리 조기 종료. |

### Play 체크리스트 (후속)

- [ ] 가스 사망 시 Die 애니만 재생, 밸브 재진입 없음

## 1. 클리어 시 결과 패널이 애니와 동시에 뜸

| 항목 | 내용 |
|------|------|
| **증상** | 마지막 오염원 제거 직후 `ClearSet` UI와 `Player_Clear` 애니가 한꺼번에 표시됨. |
| **원인** | `GameManager.ShowClear()`에서 `PlayClearAnim()` 직후 즉시 `clearSet.SetActive(true)`. |
| **해결** | `clearAnimDelay`(기본 2초) — `FreezePlayOnResult()` + `PlayClearAnim()` 후 코루틴으로 패널·클리어 SFX·별점·저장 처리. |
| **파일** | `GameManager.cs`, `Player.cs` (`PlayClearAnim`, `clearAnimActive`) |
| **Animator** | `Clear` 트리거, Any State → `Player_Clear`(Loop) — Unity에서 `Player.controller` 저장 필요 |

## 2. 사망 시 게임오버 패널이 Die 애니와 동시에 뜸

| 항목 | 내용 |
|------|------|
| **증상** | 방호복 0·타임오버 시 Die 연출 전에 게임오버 패널이 나옴. |
| **원인** | `Player.DieAndFadeOutRoutine` 끝에서 `CompletePlayerDeathSequence()` 호출 — 클립 길이(0.55초) + 페이드 후 패널. `ShowClear`와 타이밍 기준이 달랐음. |
| **해결** | `dieAnimDelay`(기본 2초) — `BeginPlayerDeathSequence()`에서 코루틴으로 패널 표시. 플레이어 페이드는 동일 2초 후 시작(패널과 맞춤). `dieGameOverFallbackDelay`는 비상용 유지. |
| **파일** | `GameManager.cs`, `Player.cs` |
| **부수 수정** | `BeginPlayerDeathSequence`에서 `StopValveSfx()`가 `if` 밖에 있던 중괄호 누락 수정 |

## 3. 맵에서 오염원 1마리 제거 후 아이템이 중화제로 초기화됨

| 항목 | 내용 |
|------|------|
| **증상** | A~C 중화 후 다음 오염원 대기·맵 이동 중 선택했던 패드/중화제가 사라지고, 다음 경고 때 항상 중화제로 돌아감. |
| **원인** | `Pollutant` HP 0 시 `activeCount <= 1`이면 `ResetToDefault()`(스캐너). 다음 `OnWarningShown()`이 `selectedIndex = FirstTreatmentIndex`(중화제)로 강제. |
| **해결** | 오염원 제거 시 `ResetToDefault()` **제거**. `OnWarningShown()`은 이미 중화 도구를 고른 상태면 선택 유지(첫 경고만 중화제 기본). 스테이지 재시작은 `ResetForStage()` → `ResetToDefault()` 그대로. |
| **파일** | `Pollutant.cs`, `ItemSelectManager.cs` |

## 4. 키 가이드·아이템 가이드 패널 토글 없음

| 항목 | 내용 |
|------|------|
| **요청** | `KeyGuidePannel` / `ItemGuide` 기본 비활성. **K** = 키 가이드, **I** = 아이템 가이드 on/off. |
| **해결** | `HelpGuideToggle.cs` — `HUD_Canvas`에 부착, 부모 오브젝트만 `SetActive` 토글. 자식은 켜 둠(부모 꺼지면 함께 숨김). 게임오버·일시정지 중 입력 무시. |
| **로딩 안내** | `LoadingGuideTxt` 메시지에 K/I 설명 추가. |
| **파일** | `HelpGuideToggle.cs`, `LoadingGuideTxt.cs`, `GameScene.unity` |
| **Hierarchy** | 부모 `KeyGuidePannel`·`ItemGuide`만 체크 해제, 자식 UI는 활성 유지 |

## 5. 틀린 아이템 접촉 시에도 중화 VFX(CFXR) 재생

| 항목 | 내용 |
|------|------|
| **증상** | 추천과 다른 중화 도구로 접촉해도 플레이어 중화 파티클이 켜짐. 방호복만 감소·오염원 HP는 안 줄어듦(판정은 정상). |
| **원인** | `RefreshNeutralizationVfx()`가 `IsNeutralizationItemSelected()`만 검사 — 스캐너가 아니면(아무 중화 도구면) VFX ON. |
| **해결** | 접촉 중 A~C 오염원 중 `IsSelectedItemRecommendedFor(pollutant)`가 true일 때만 VFX. 가스(D)는 밸브 애니만(VFX 없음). Z/X 아이템 변경 시 `ItemSelectManager.UpdateUI()`에서 `RefreshNeutralizationVfx()` 호출. |
| **파일** | `Player.cs`, `Pollutant.cs` (`IsPlayerContactActive`), `ItemSelectManager.cs` |

## 6. Git 브랜치가 master와 어긋나 PR 생성 불가

| 항목 | 내용 |
|------|------|
| **증상** | `260605_문서작성분`에서 GitHub PR 생성 시 base `master`와 맞지 않음. 브랜ches 화면에 **45 commits behind**, **2 commits ahead** 표시. |
| **원인** | 작업 브랜치가 오래된 베이스에서 갈라짐. `master`에 머지된 PR(#15~#18 등) 45개가 로컬 작업 브랜치에 없음. rebase 시 add/add 충돌 다수(문서·씬·스크립트·프리팹). `merge`는 unrelated histories로 거부. |
| **해결** | `origin/master` 기준 새 브랜치 **`260606스플래시추가`** 생성 → `260605_문서작성분` 트리를 `git reset --soft origin/master`로 **커밋 1개**로 정리 → push. 결과: master 대비 **0 behind / 1 ahead**, PR 가능. |
| **커밋** | `3d34332` — 스플래시씬·가이드 패널·클리어 연출·VFX 수정 및 문서 갱신 |
| **PR** | base `master` ← compare `260606스플래시추가` |
| **원칙** | 기능 브랜치는 **`master` 최신 fetch 후** 분기. 오래된 브랜치에 커밋만 쌓지 않기. PR 전 `git fetch origin` 후 behind/ahead 확인. |

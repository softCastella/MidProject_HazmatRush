## 1. 클리어 패널 버튼·키 입력 무반응 (미해결 — 패치 롤백)

| 항목 | 내용 |
|------|------|
| **증상** | 스테이지 클리어·F1 강제 클리어 후 `ClearSet` 표시·별 채움은 됨. **다음 스테이지 / 타이틀 버튼** 클릭·Enter·Space 무반응. Console에 `GoToNextStage 클릭` 로그 없음. |

| **롤백** | 입력 여전히 실패 + `'Player' AnimationEvent has no function name specified!` 경고 겹침 → `git restore`로 `GameManager.cs`, `ClearPanelUI.cs`, `GameScene.unity`, `Timer.cs` **마지막 커밋 상태** 복구. |
| **추정 원인 (재조사 필요)** | ① `InventoryContainer`·`InvLbContainer` 등 HUD sibling이 `Result_HUD` 위에 겹쳐 레이캐스트 차단. ② `GameManager`에 `RecoveryItemInventory`가 **중복 부착**되어 JSON 로드 2회(머지 실수). ③ 클리어만 `ClearPanelUI.Apply`·추가 레이캐스트 처리로 게임오버와 경로 이원화. |
| **파일** | `GameManager.cs`, `ClearPanelUI.cs`, `Timer.cs`, `GameScene.unity` |

## 3. `Player` AnimationEvent — functionName 비어 있음 (해결)

| 항목 | 내용 |
|------|------|
| **증상** | 클리어·사망 연출 중 Console: `'Player' AnimationEvent has no function name specified!` |
| **원인** | `Player_Clear.anim`·`Player_Die.anim` 타임라인에 **functionName 빈** 이벤트 1개씩 존재. |
| **해결** | 두 클립 `m_Events: []`로 비움. 결과 패널 타이밍은 `GameManager` `clearAnimDelay` / `dieAnimDelay`로 처리 — 이벤트 콜백 불필요. |
| **파일** | `Assets/Animations/Player_Clear.anim`, `Assets/Animations/Player_Die.anim` |
| **상태** | ✅ **해결** |

## 4. 인벤 표시명 — 프리팹 이름 변경해도 UI 갱신 안 됨 (해결·참고)

| 항목 | 내용 |
|------|------|
| **증상** | `invTimeRecovPrefab` 등 프리팹 이름을 `방호복회복`으로 바꿔도 인벤 칸 아래 글자는 `방호복 회복제` 유지. |
| **원인** | 인벤 Name 텍스트는 **프리팹 이름이 아니라** `recovery_items.json`의 `displayName`. `RecoveryItemInventoryUI.ApplyInvItemViewLayout`에서 JSON 값으로 덮어씀. |
| **해결** | `Assets/Data/recovery_items.json`의 `displayName` 수정 (사용자 적용). |
| **파일** | `recovery_items.json`, `RecoveryItemInventoryUI.cs` |
| **상태** | ✅ **해결** (데이터 수정) |

## 5. 시간연장 인벤 아이콘이 유난히 작음 (해결)

| 항목 | 내용 |
|------|------|
| **증상** | 인벤에서 시간연장(시계) 아이콘만 방호복 대비 **현저히 작음**. 약 **1.5배** 필요. |
| **원인** | ① `ApplyInvItemViewLayout`이 모든 아이콘을 **44×44**로 고정·프리팹 `localScale` 리셋. ② `TimeWatch.png` PPU **5**(맵용)·스프라이트 rect **345×474**에 투명 여백 많음 → `preserveAspect` 시 실제 그림만 작게 보임. ③ 방호복은 `Flasks` 작은 rect라 상대적으로 큼. |
| **해결** | `RecoveryItemInventoryUI` — id **2**(시간연장)만 `InvImageSizeTime = 66f` (**44의 1.5배**). 맵용 `TimeWatch` PPU·스프라이트는 **변경 없음**. |
| **프리팹만으로 불가** | 런타임 레이아웃이 size/scale을 덮어씀. 프리팹만 조정하려면 **인벤 전용 타이트 크롭 스프라이트**를 `invTimeRecovPrefab`에만 할당하는 방법 가능(맵 프리팹 분리 유지). |
| **파일** | `RecoveryItemInventoryUI.cs`, `invTimeRecovPrefab.prefab`, `TimeWatch.png` |
| **상태** | ✅ **해결** (코드 1.5배) |

## 8. 미해결·다음 작업 (우선순위)

1. **클리어 패널 입력** — 게임오버(F2)와 **동일한 최소 경로**로 재조사. `InventoryContainer`·`InvLbContainer` 숨김 + `Result_HUD` sibling만 변경, nested Canvas·HUD 전체 비활성 **금지**.
2. **게임오버 순차 패널** — `dieAnimDelay`를 **unscaled 타이머**(`Timer` 또는 `GameManager` 단일 메서드)로 재적용 (클리어와 쌍으로).
3. **`GameManager` 중복 `RecoveryItemInventory`** — 씬에서 제거 후 JSON 로그 1회 확인.
4. (선택) 시간연장 **인벤 전용 스프라이트** 크롭 — 맵 PPU와 분리해 프리팹만으로 비율 맞추기.

## 1. 경고 구간 — 전체 일시정지가 아닌 부분 프리즈

| 항목 | 내용 |
|------|------|
| **증상** | 경고 문구·안내 연출 중에도 배경·이동·타이머가 계속 진행되어 UX 혼란. |
| **1차 시도** | `Time.timeScale = 0` + BGM dim (일시정지와 동일) → 경고 깜빡임·BGM까지 멈춤, 과함. |
| **해결** | **배경·이동·타이머만** 멈춤. BGM·경고 깜빡임·아이템 안내 연출은 정상 진행. |
| **이동** | `WarningAndSpawn`에서 `player.canMove = false` → 오염원 등장 후 `true` |
| **타이머** | `timer.StopCountdown()` → 오염원 등장 후 `isRunning = true` |
| **배경** | 기존 `awaitingSpawn` → `scroll.PauseScroll()` 유지 |
| **키 입력** | `PollutantManager.IsWarningFreeze`(=`awaitingSpawn`) 동안 Z/X·C/V/Space·K/I 차단 |
| **파일** | `PollutantManager.cs`, `ItemSelectManager.cs`, `RecoveryItemInventory.cs`, `HelpGuideToggle.cs` |

## 2. 맵에 착지한 회복 아이템 — 배경 스크롤 정지

| 항목 | 내용 |
|------|------|
| **증상** | 오염원 중화 후 드랍·착지한 회복 아이템이 맵에 남아 있는데 배경이 스크롤됨. |
| **해결** | `RecoveryItemManager.landedMapItemCount` 추적 (`OnMapRecoveryItemLanded` / `Removed`). `ShouldPauseBackgroundScroll()`에서 착지 아이템 있으면 `PauseScroll`. |
| **파일** | `RecoveryItem.cs`, `RecoveryItemManager.cs`, `PollutantManager.cs` |

## 3. 맵 구간 전환 — 맵 끝 도달 시에만 페이드

| 항목 | 내용 |
|------|------|
| **증상** | 구간 오염원 전부 중화 직후 `MapAdvanceRoutine`이 바로 시작·배경 재개. 회복 아이템 수집·이동 판단이 어려움. |
| **해결** | `StartSegmentAfterAbcClear` → `pendingMapAdvance = true` + `"오른쪽으로 이동하세요"` (`ShowGuideImmediate`). 플레이어 X ≥ `mapEndX` 도달 시에만 `MapAdvanceRoutine` 시작. |
| **회복 아이템** | 잔존 아이템 있어도 맵 끝 도달 시 전환 가능. 전환 시 `ClearMapRecoveryItems()`. |
| **안내** | 맵 끝 도달 전까지 안내 유지, 페이드 직전 `HideGuide`. |
| **복구** | 전환 후 `ResetRange`·`segmentMovementUnlocked = false`·`UpdateBackgroundScroll()` — 기존 이동·스크롤 규칙 복귀. |
| **파일** | `PollutantManager.cs`, `GuideTxt.cs` |

## 4. 스테이지 클리어 — 애니 2초 정지 + 회복 아이템 자동 획득

| 항목 | 내용 |
|------|------|
| **클리어 애니** | `Player_Clear` 루프 클립은 유지. `clearAnimDelay`(2초) 후 `FreezeClearAnim()` → `anim.speed = 0`으로 현재 프레임 정지 → ClearSet 표시. |
| **회복 아이템** | `ShowClear()` 진입 시 `AutoCollectMapRecoveryItems()` — 맵 잔존 아이템을 **인벤에 자동 추가** (아크 중이어도). 이후 `ClearMapRecoveryItems()`로 맵 오브젝트 정리. |
| **인벤 가득 참** | 현재 JSON 2종·동일 id 스택 구조상 **실플레이에서 발생하지 않음**. `EnsureSlotRootCount`로 칸 동적 추가. |
| **제거** | `clearRecoveryGraceSeconds` 수집 여유 대기 — 자동 획득으로 불필요. |
| **파일** | `GameManager.cs`, `Player.cs`, `RecoveryItem.cs`, `RecoveryItemManager.cs` |

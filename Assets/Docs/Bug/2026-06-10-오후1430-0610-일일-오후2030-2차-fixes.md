## 1. 스테이지 BGM이 항상 0번만 재생

| 항목 | 내용 |
|------|------|
| **증상** | `stage_data.json` `bgmIndex` 1·2 스테이지도 첫 곡과 동일하게 들림. |
| **원인 1** | `AudioManager.OnSceneLoaded` / `Start`가 `GameScene`마다 `PlayGameBGM()` → `PlayStageBgm(0)` 호출. |
| **원인 2** | Splash 등 중복 `AudioManager`가 먼저 뜨면 `stageBgmClips` 미병합 → `PlayStageBgm(n)`이 `gameBGM`(0번과 동일)으로 fallback. |

| **파일** | `AudioManager.cs`, `StageManager.cs`(기존 호출 유지) |

| **파일** | `Player.cs`, `Pollutant.cs` |

## 세션 오후 20:30 — 게임오버 패널 타이밍 (2차)

### 8. 사망 연출 순서 — Die → 페이드 → 1초 → 패널

| 항목 | 내용 |
|------|------|
| **증상** | `dieAnimDelay`(2초) 직후 **게임오버 패널과 플레이어 페이드가 동시**에 시작됨. 의도는 Die 유지 → 페이드 → 잠깐 여백 → 패널. |
| **원인** | `GameManager.ShowGameOverPanelAfterDeathAnim`과 `Player.DieAndFadeOutRoutine`이 같은 `dieAnimDelay`만 대기 후 각각 패널·페이드를 시작. |
| **해결 (1단계)** | `GameManager` — 패널 전 `player.dieFadeDuration` 추가 대기 (페이드 종료 후 패널). |
| **해결 (2단계)** | `diePanelDelayAfterFade`(기본 1초) 추가 — 페이드 끝난 뒤 1초 더 대기 후 `gameOverSet`·게임오버 SFX. `dieGameOverFallbackDelay` 5초로 상향. |
| **파일** | `GameManager.cs`, `GameScene.unity` |

### 합의 타임라인

```text
T=0s     Die 트리거 (`Player.StartDeathSequence`)
T=2s     dieAnimDelay — Player 페이드 시작 (`dieFadeDuration` 기본 0.5s)
T=2.5s   페이드 완료
T=3.5s   diePanelDelayAfterFade(1s) 후 GameOverSet + SFX
```

| Inspector (`GameManager`) | 기본 |
|---------------------------|------|
| `dieAnimDelay` | 2 |
| `diePanelDelayAfterFade` | 1 |
| `dieGameOverFallbackDelay` | 5 |

`Player.dieFadeDuration`은 `Player` Inspector에서 조절 — 패널 대기는 `dieAnimDelay` + `dieFadeDuration` + `diePanelDelayAfterFade` 합산.

- [x] 이어서 플레이어 페이드 아웃 (약 0.5초)
- [x] 페이드 후 약 1초 뒤 게임오버 패널 (패널과 Die 동시 아님)

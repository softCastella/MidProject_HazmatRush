스플래시 → 타이틀 → 인트로 구간 페이드·암전·흰 화면 대기 관련 보고·수정 기록입니다.

---

## 1. 인트로가 「확」 튀어 보임 (타이틀 → 인트로)

| 항목 | 내용 |
|------|------|
| **증상** | Start 후 인트로 스토리가 갑자기 나타남. 검은 암전 후 페이드인이 자연스럽지 않음. |
| **원인** | 타이틀은 CanvasGroup 투명화만 하고, 인트로 `Awake`에서 오버레이 alpha 0 → `Start`에서야 검게 덮음(1프레임 번쩍 가능). 타이틀 암전과 인트로 페이드인이 이어지지 않음. |
| **해결** | `TitleSceneFade` 추가 — 흰 `FadeOverlay` 0→1 암전 후 인트로 비동기 로드. `AutoScrollIntro.fadeInFromTitle` 시 `Awake`부터 오버레이 alpha 1(흰 화면) 유지 → `FadeInThenScroll()`에서 SmoothStep으로 0.8초 페이드인. |
| **파일** | `TitleSceneFade.cs`, `AutoScrollIntro.cs`, `SceneLoadUI.cs`, `TitleScene.unity`, `IntroStoryScene.unity` |

---

## 2. 타이틀 → 인트로 암전이 너무 김

| 항목 | 내용 |
|------|------|
| **증상** | Start 누른 뒤 검은/흰 화면만 오래 보임. |
| **원인** | 타이틀 페이드아웃 + 동기 `LoadScene` + 인트로 페이드인이 **순차 대기**로 겹침. |
| **해결** | 타이틀·인트로 모두 `LoadSceneAsync` + `allowSceneActivation = false`로 **페이드와 로드 병행**. 타이틀 흰 암전 `fadeOutDuration` 0.25초. |
| **파일** | `TitleSceneFade.cs`, `AutoScrollIntro.cs` |

---

## 3. 스플래시 → 타이틀 흰 화면 대기가 김

| 항목 | 내용 |
|------|------|
| **증상** | 로고가 작아지며 사라진 **뒤** 흰 화면만 길게 남음. (로고 연출 자체는 괜찮음) |
| **원인** | 로고 alpha 0 이후에도 `fadeOutDuration` 루프가 끝까지 돌고, `LoadScene` 동기 대기. |
| **해결** | 스플래시 시작 시 타이틀 `LoadSceneAsync` 선행. 로고 alpha ≤ 0.02이면 페이드아웃 **조기 종료**. 로드 완료(0.9) 후 즉시 씬 활성화. 별도 검은 암전(`FadeScreenToBlack`) 제거. |
| **파일** | `SplashController.cs`, `SplashScene.unity` (`fadeOutDuration` 1.5초 유지) |

---

## 4. 스플래시 → 타이틀 타이틀 페이드인 불필요

| 항목 | 내용 |
|------|------|
| **증상** | 스플래시 후 타이틀이 검은 화면에서 다시 페이드인 — 이중 전환 느낌. |
| **해결** | `TitleSceneFade`의 스플래시 진입 페이드인(`fadeInFromSplash`) **전부 제거**. 타이틀 즉시 표시. |
| **파일** | `TitleSceneFade.cs`, `SplashController.cs` |

---

## 5. 인트로 → 로딩 암전 색상

| 항목 | 내용 |
|------|------|
| **증상** | 타이틀→인트로는 흰 오버레이인데, 인트로 끝 암전이 흰색으로 남을 수 있음. |
| **해결** | `ExitToLoadingRoutine()` 시작 시 오버레이 RGB를 **검정**으로 바꾼 뒤 기존 0.5초 암전 유지. |
| **파일** | `AutoScrollIntro.cs` |

---

## 6. 현재 씬 전환 타이밍 (합의값)

| 구간 | 연출 | 시간(기본) |
|------|------|------------|
| 스플래시 → 타이틀 | 로고 페이드아웃(1.5s) + 흰 배경, 암전 없음 | 로드 병행 |
| 타이틀 → 인트로 | 흰 오버레이 암전 | 0.25s |
| 인트로 진입 | 흰 화면 SmoothStep 페이드인 | 0.8s |
| 인트로 → 로딩 | 검은 암전 | 0.5s |

Inspector에서 `TitleSceneFade.fadeOutDuration`, `AutoScrollIntro.fadeInDuration`으로 조절.

---

## 7. 재발 방지

| 주의点 | 내용 |
|--------|------|
| 이중 페이드 | 스플래시 암전 + 타이틀 페이드인 다시 넣지 않기(요청 시만). |
| 인트로 `Awake` | `fadeInFromTitle`일 때 오버레이 **반드시** 불투명(1)로 시작. 0으로 두면 번쩍임 재발. |
| 로드 대기 | 씬 전환은 가능하면 `LoadSceneAsync` + 페이드 병행. |
| 색상 | 타이틀→인트로 = **흰색**, 인트로→로딩 = **검정** — 경로별로 분리 유지. |

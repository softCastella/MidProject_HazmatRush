## 17. 배경 정지 후 플레이·걷기가 느리게 느껴짐 (체감)

| 항목 | 내용 |
|------|------|
| **증상** | 1차 구간보다 오염원 등장·전투·회복 아이템 구간에서 이동·걷기가 느리게 느껴짐. |
| **원인** | `Player.moveSpeed`는 동일. `PollutantManager.ShouldPauseBackgroundScroll()`로 배경 UV 스크롤만 멈춤 → 1차의 「캐릭터+배경」 동시 이동 체감이 사라짐. 걷기 클립(`Player_Move`) 속도는 이동 수치와 별도라 간극 가능. |
| **해결** | `PollutantManager.IsBackgroundScrollLocked()` 공개. `Player.GetMoveSpeed()` — 잠금 중 `moveSpeed × bgLockedSpeedMultiplier`. `GameScene` 튜닝: `moveSpeed` **200** · `scrollSpeed` **0.2** · `bgLockedSpeedMultiplier` **1.7** (잠금 시 유효 340). 걷기 애니는 Animator `Player_Move` Speed·클립 `SampleRate`로 추가 조절. |
| **파일** | `Player.cs`, `PollutantManager.cs`, `GameScene.unity`, `Prefabs/Game/Player.prefab` |

### Play 체크리스트

- [ ] 1차 구간: 좌우 입력 시 배경·캐릭터 함께 흐름 (`scrollSpeed` 0.2)
- [ ] 오염원 경고·전투 중: 배경 정지 · 플레이어는 1차보다 **덜 느리게** (×1.7)
- [ ] 회복 아이템 맵에 있을 때도 동일 가속 · 줍은 뒤 1차 구간 복귀 시 배율 해제
- [ ] 걷기 스프라이트가 바닥 미끄러짐 없이 보이는지 (필요 시 `Player_Move` Speed 조절)

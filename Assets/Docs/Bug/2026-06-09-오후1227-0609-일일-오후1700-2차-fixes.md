방호복 HP를 우측 상단 고정 HUD로 옮기고, 7단계 Fill 이미지·바 내 `000%` 표시를 넣는 과정과, 오염원 HP 슬라이더·접촉 판정에서 재발한 버그 기록입니다.

---

## 1. 방호복 HP — 슬라이더 대신 7단계 Fill 이미지

| 항목 | 내용 |
|------|------|
| **증상** | 기존 `Slider` fill은 계단형 스프라이트 모션과 맞지 않음. |
| **의도** | `Fill_0`=100%(7칸) … `Fill_6`=1칸. HP 비율에 맞는 **한 장**만 `SetActive(true)`. |
| **해결** | `ProtectionHpBarUI.cs` 추가. `FillArea` 아래 `Fill_0`~`Fill_6` 자동 탐색. `Player.protectionHpBar` → `SetProtection(cur, max)`. |
| **텍스트** | `protectionHp` 자식 `Text (TMP)`에 `D3%` 형식 (`100%` → `100%`, `9%` → `009%`). 별도 `ProtectionNum` 제거. |
| **파일** | `ProtectionHpBarUI.cs`, `Player.cs`, `GameScene.unity`, `Player.prefab` |

---

## 2. FillArea를 Image로 가정 (초기 스크립트 오해)

| 항목 | 내용 |
|------|------|
| **증상** | `fillSprites` + `FillArea.GetComponent<Image>()` 경로가 동작하지 않음. |
| **원인** | 씬에서 `FillArea`는 **RectTransform + Mask** 컨테이너. Image 없음. 실제 그래픽은 자식 `Fill_0`~`Fill_6` 각 Image + 스프라이트(`5_0`~`5_6`). |
| **해결** | 스프라이트 배열·`fillImage` 필드 제거. **자식 토글만** 사용. |
| **파일** | `ProtectionHpBarUI.cs` |

---

## 3. 방호복 0%인데 Fill_6(1칸)이 남음

| 항목 | 내용 |
|------|------|
| **증상** | `curProtection == 0`이어도 가장 낮은 단계 Fill이 보임. |
| **원인** | `ProtectionToStep(0, max)`가 ratio 0 → step 6(`Fill_6`) 반환. |
| **해결** | `current <= 0`이면 step `-1` → `Fill_0`~`Fill_6` **전부 비활성**, 텍스트만 `000%`. |
| **파일** | `ProtectionHpBarUI.cs` |

---

## 4. 오염원 HP 슬라이더가 우측 상단에 잘려 고정

| 항목 | 내용 |
|------|------|
| **증상** | `pollutantHpSlider`가 타이머·방호복 바 근처 우측 상단에 잘린 채 보임. 오염원을 따라가지 않음. |
| **원인 1** | `pollutantHpSlider`가 `HpBar`(우측 상단 앵커) **자식**으로 들어가 있음. |
| **원인 2** | `WorldSpaceUIFollower`가 화면 좌표를 **루트 캔버스 기준**으로 구한 뒤 **자식 localPosition**에 대입 — 부모가 `HpBar`일 때 좌표계 불일치. |
| **해결** | 슬라이더를 `HUD_Canvas` 직속으로 이동. Follower는 **직계 부모 RectTransform** 기준으로 local 좌표 변환. `worldTarget`은 Inspector **None** — 접촉 시 `Pollutant.ShowContactBars`가 해당 오염원 `SpriteRenderer`로 런타임 할당. |
| **파일** | `WorldSpaceUIFollower.cs`, `GameScene.unity` |

---

## 5. 접촉 없이 중화 · 떨어져도 VFX/SFX 유지

| 항목 | 내용 |
|------|------|
| **증상** | 트리거 밖에서도 오염원 HP 감소·중화 VFX. 접촉 중 떨어져 나가도 중화 VFX·SFX·밸브 연출이 계속됨. |
| **원인** | `Pollutant.LateUpdate`가 **넓은 padding bounds**로 트리거 없이 `BeginPlayerContact` + `ApplyPlayerContactDamage` 호출. `OnTriggerExit`도 padding 겹침 시 해제 무시. `IsPlayerContactActive()`가 `playerInTrigger` 플래그만 참조. |
| **해결** | [회의록 §4.3](../회의록/2026-06-05-시각미상-플레이어-오염원-로직-검토.md)에 맞춤: `LateUpdate` bounds 우회 **삭제**. 데미지는 `FixedUpdate` + `IsPlayerInContact()`(D+밸브 시 padding 0.15f만). `OnTriggerExit`는 padding **0**. `IsPlayerContactActive()`는 bounds 겹침 반영. |
| **파일** | `Pollutant.cs` |

## 1. 첫 오염원 등장 후에도 -403에서 막힘

| 항목 | 내용 |
|------|------|
| **증상** | 가이드 후 1차 구간 끝(-403)에서 멈춤. 첫 오염원 등장 후에도 오른쪽(오염원·가스 쪽) 이동 불가. |
| **원인** | `UnlockMapSegmentMovement()`가 스폰 실패·활성 오염원 선행 등 일부 경로에서 호출되지 않음. 입력 없을 때도 `Clamp`가 X > -403 위치를 -403으로 끌어당김 ([Bug 2026-06-04 §4](2026-06-04-시각미상-gameplay-fixes.md) 재발). |
| **해결** | `PollutantManager.TryUnlockSegmentMovement()` — `mapEndX`로 `rightLimit` 확장, 경고·스폰 코루틴 끝·활성 오염원 존재 시 항상 시도. `Player.Update` — **이동 입력 있을 때만** `Clamp`. |
| **파일** | `PollutantManager.cs`, `Player.cs` |
| **상태** | ✅ 수정 |

## 2. 플레이어·배경 속도 차이 (체감)

| 항목 | 내용 |
|------|------|
| **증상** | 플레이어만 느리게 하면 배경이 상대적으로 더 빨라 “배경만 미친 듯 흐름”. `moveSpeed`만 5로 낮추면 체감 더 악화. |
| **원인** | 단위 불일치. `moveSpeed` = 월드 유닛/초, `scrollSpeed` = UV(0~1)/초. 배경 메시 가로 1920 × 타일 1 → **배경 유닛/초 ≈ scrollSpeed × 1920**. |
| **공식** | `scrollSpeed ≈ (moveSpeed / 1920) × 패럴랙스비율` — **0.5** 권장(공장 벽이 살짝 뒤따라오는 느낌). **1.0** = 완전 동기화. |
| **GameScene 현재값** | `moveSpeed = 400`, `scrollSpeed = 0.104` (400 × 0.5 / 1920) |
| **파일** | `GameScene.unity` (Inspector), `Background0.prefab` 기본 `scrollSpeed 0.2`는 씬에서 덮어씀 |
| **상태** | ✅ 반영 · 🟡 실플레이 체감 재확인 권장 |

## 3. 고속 이동 시 오염원 접촉 중간 끊김

| 항목 | 내용 |
|------|------|
| **증상** | `moveSpeed` 200~400에서 접촉 중 HP·방호복 감소가 끊기고 오염원 HP가 초기화됨 (`EndPlayerContact`). |
| **원인** | `Update`에서 `rb.MovePosition` → 물리 트리거(`OnTriggerStay`)와 프레임 어긋남. 1 FixedUpdate당 8유닛(400×0.02) 이동 시 트리거 한 박자 스킵 → `OnTriggerExit`. `scrollSpeed` 변경과 **무관**. |
| **1차 시도** | 프레임당 `maxStep` 상한 — 300~400 체감 속도를 150 수준으로 눌러 느려짐. 접촉만으로는 불충분. |
| **해결** | **①** `Player` — 입력·애니 `Update`, **이동 `FixedUpdate`** (`moveSpeed × fixedDeltaTime`). **②** `Pollutant` — `OnTriggerStay` 처리 프레임은 `LateUpdate` bounds 겹침으로 데미지 보정(A~C/D 동일). **③** `OnTriggerExit` — `GetContactOverlapPadding`(이동량·플레이어 콜라이더 반영)으로 잘못된 해제 방지. `BeginPlayerContact` / `ShowContactBars` 공통화. |
| **파일** | `Player.cs`, `Pollutant.cs` |
| **상태** | ✅ 수정 · 🟡 400 속도·좌우 연타 Play 검증 |

## 4. 좌우 연속 전환 시 가속 느낌 (미수정 · 분석)

| 항목 | 내용 |
|------|------|
| **증상** | 좌우 방향을 연속으로 바꿀 때 등속 이동인데 약간 가속·관성처럼 느껴짐. |
| **원인 추정** | **①** `Background.SmoothDamp`(`stopSmoothTime 0.2`) — 키가 잠깐 떨어지면 배경만 관성 감속·재가속. **②** `Update` 입력 vs `FixedUpdate` 이동 타이밍 차이. 플레이어 코드에 가속 변수는 없음. |
| **권장 대응** | 배경 방향 전환 시 `scrollVelocity` 리셋 또는 `stopSmoothTime` 축소. 연속 이동 중 방향만 바뀔 때 속도 감쇠 생략 검토. |
| **상태** | 🟡 분석만 · 수정 보류 |

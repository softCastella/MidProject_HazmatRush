스플래시 씬 연출·`splashSFX`·타이틀 BGM 씬 전환 관련 보고·수정 기록입니다.

---

## 1. 스플래시 SFX가 로고보다 먼저 재생됨

| 항목 | 내용 |
|------|------|
| **증상** | 씬 시작 직후 소리가 나고, 로고 페이드인과 어긋남. |
| **원인** | `SplashController`가 `PlaySplash()` 시작 시점(또는 페이드인 코루틴 첫 줄)에서 즉시 `PlaySplashSfx()` 호출. 로고 `alpha`가 0인 상태에서 풀 볼륨 재생. |
| **해결** | `splashSfxDelay`(기본 0.15초) — 페이드인이 진행된 뒤 SFX 재생. 볼륨 페이드는 사용하지 않음(작게 들리는 부작용 방지). |
| **파일** | `SplashController.cs` |

---

## 2. 스플래시 SFX를 Controller에 직접 붙임

| 항목 | 내용 |
|------|------|
| **증상** | `AudioManager`를 쓰는 프로젝트인데 `SplashController`에 `AudioSource`를 별도 추가. |
| **원인** | 스플래시가 첫 씬이라 `AudioManager`가 없을 수 있다고 가정. |
| **해결** | `SplashScene`에 `AudioManager` 배치 + `splashClip` 연결. `PlaySplashSfx()` / `StopSplashSfx()`를 `AudioManager`로 통일. `SplashController`는 `Instance`만 호출. |
| **파일** | `AudioManager.cs`, `SplashController.cs`, `SplashScene.unity` |

---

## 3. 타이틀 BGM이 인트로·로딩까지 계속 재생됨

| 항목 | 내용 |
|------|------|
| **증상** | 시작 버튼 → `IntroStoryScene` → `LoadingScene` 동안 타이틀 BGM이 끊기지 않음. |
| **원인** | `AudioManager`가 `DontDestroyOnLoad`인데 `PlayBGMForScene()`이 `TitleScene` / `GameScene`만 처리. 인트로·로딩 진입 시 `StopBGM()` 미호출 → 이전 BGM 유지. |
| **해결** | 타이틀·게임이 아닌 씬 로드 시 `StopBGM()` 호출. |
| **파일** | `AudioManager.cs` |

---

## 4. 타이틀·게임 BGM 전환이 딱딱 끊김

| 항목 | 내용 |
|------|------|
| **증상** | 씬 전환·BGM 시작/정지가 순간적으로 바뀜. |
| **해결** | `bgmFadeDuration`(기본 0.8초) — Title/Game 진입 시 페이드 인, 이탈 시 페이드 아웃 후 정지. 클립 교체 시 기존 BGM 페이드 아웃 → 새 BGM 페이드 인. `Time.unscaledDeltaTime` 사용(일시정지 중 씬 전환 대비). |
| **파일** | `AudioManager.cs` |

## 7. 재발 방지·알려진 잠재 이슈

| 주의点 | 내용 |
|--------|------|
| BGM 씬 규칙 | `PlayBGMForScene`: Title/Game만 재생, 그 외는 `StopBGM`(페이드 아웃). **새 씬 추가 시** 여기 분기 확인. |
| 스플래시 SFX | `splashSfxDelay`로 페이드인과 청각 타이밍 맞출 것. 볼륨 페이드는 SFX에 쓰지 않음. |
| `SplashScene` `AudioManager` | `sfxVolume`이 `TitleScene`과 다르면 스플래시 SFX 크기 차이 남 — Inspector에서 맞출 것. |
| (잠재) `PollutantSpawnPlan` | `GameScene` 첫 진입 시 `preparedStageIndex == -1`이면 로딩 때 확정한 배치가 `Prepare()`로 다시 랜덤될 수 있음 — 별도 이슈. |

## 1. 오염원 통과 불가 / 이동 범위가 오염원에 막힘

| 항목 | 내용 |
|------|------|
| **증상** | 오염원 앞에서 더 이상 오른쪽(또는 왼쪽)으로 가지 못함. 통과가 안 됨. |
| **원인** | 스폰·중화 후 `GrowRange(GetEdgeX)`로 `leftLimit`/`rightLimit`이 오염원 위치에 맞춰 조여짐. `ClampPassThrough` 계열도 트리거 진입 전에 막는 경우 있음. |
| **해결** | `GrowRange`/`GetEdgeX`/`RefreshMoveRange`의 범위 확장 루프 **제거**. 첫 스폰 시 `UnlockMapSegmentMovement()` 한 번만 호출. 이동은 `Clamp(leftLimit, rightLimit)`만 사용. |
| **파일** | `Player.cs`, `PollutantManager.cs` |
| **상태** | ✅ 해결 확인 |

## 2. 맵에 2마리인데 1마리 제거 후 두 번째가 안 나옴

| 항목 | 내용 |
|------|------|
| **증상** | `mapPollutants: [2]` 등 맵당 2마리 스테이지에서 1마리 중화 후 두 번째 경고·스폰이 없음. 플레이어가 오른쪽 끝(769)까지 가서 벽에 붙어 걷기만 함. |
| **원인** | `FadeOutAndDestroy` 시작 시 `RefreshMoveRange` → `NotifyQueueAdvanceReady` 호출되지만, 페이드 중(약 0.7초) `activeCount > 0`이라 `HasAnyActive()`가 true → 다음 스폰 예약(`queueSpawnReady`) 실패. `OnDestroy` 이후 재호출 없음. |
| **해결** | 페이드 시작 시 `activeCount`/`activeAbcCount` **선차감** (`clearedActiveCount` 플래그로 `OnDestroy` 이중 차감 방지). 이후 `NotifyQueueAdvanceReady` 정상 동작. |
| **파일** | `Pollutant.cs`, `PollutantManager.cs` |
| **상태** | ✅ 수정 완료 |

| **파일** | `stage_data.json`, `PollutantSpawnPlan.cs`, `PollutantManager.cs`, `StageManager.cs` |

## 9. 재발 방지 메모

| 주의点 | 내용 |
|--------|------|
| 스폰 예약 | 오염원 제거 시 `activeCount`와 `NotifyQueueAdvanceReady` 타이밍 맞출 것. 페이드 중에도 “활성 없음”으로 다음 큐 진행 가능해야 함. |
| 맵 전환 | `PollutantSpawnPlan.Prepare()`는 스테이지 시작 시 1회만. `AdvanceMap()` 후 `revealIndex=0` + `BuildPreloadedPollutants()`만. |
| 가이드 | 튜토리얼(1-1) / 맵 이동 안내 / 패널티 안내는 **서로 다른 조건**으로 분리 유지. |
| 프리팹 | 오염원 프리팹 스프라이트 GUID가 깨지면 코드 수정 없이 **이미지만 안 보임** — 에셋 누락 먼저 확인. |

## 5. 일시정지 「종료하기」가 게임/타이틀로 돌아감

| 항목 | 내용 |
|------|------|
| **증상** | 일시정지 `quitBtn` 클릭 시 앱 종료 대신 플레이 재개 또는 타이틀 씬 로드처럼 보임. |
| **원인** | `Time.timeScale = 0` 상태에서 종료 처리 불안정 · `SceneLoadUI`만 연결 시 일시정지 컨텍스트 미정리. |
| **해결** | `SceneLoadUI.QuitApplication()` — 종료 전 `Time.timeScale = 1f`. `GameManager.QuitGame()` — pause 해제 후 호출. Pause `quitBtn` OnClick → `GameManager.QuitGame`. 타이틀 `quitBtn` → `SceneLoadUI.QuitButton`. |
| **파일** | `SceneLoadUI.cs`, `GameManager.cs`, `TitleScene.unity`, `GameScene.unity` |

### Play 체크리스트

- [ ] 타이틀 종료하기 → Play 종료 / exe 닫힘
- [ ] 게임 ESC → 종료하기 → Play 종료 / exe 닫힘 (타이틀 씬 로드 **아님**)

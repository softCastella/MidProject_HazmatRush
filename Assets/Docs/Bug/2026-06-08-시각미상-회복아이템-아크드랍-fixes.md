# 2026-06-08 시각미상 — 회복 아이템 아크 드랍 이슈 정리 (원인 · 해결)

| **작성** | 2026-06-08 · **시각 미상** (파일명 규칙: [문서-이름-규칙.md](../문서-이름-규칙.md)) |
| **관련** | [회복 드랍 연출 합의](../회의록/2026-06-08-시각미상-회복아이템-드랍-연출-합의.md) · [회복 인벤 설계](../회의록/2026-06-06-시각미상-회복아이템-인벤-설계-합의.md) |

오염원 정화 후 회복 아이템이 **아크 점프 없이 제자리에 생기거나**, **땅에 묻혀** 보이는 문제 보고·수정 기록입니다.

---

## 1. 아크 점프가 안 보임 (연출이 없는 것처럼 보임)

| 항목 | 내용 |
|------|------|
| **증상** | 오염원 중화 후 회복 아이템이 튀어 오르지 않고 바닥에 그냥 나타남. |
| **오해** | `RecoveryItem` / `StartDropArc` 미동작으로 보였으나, Console에는 드랍 로그만 있고 아크 로그는 없었음. |
| **원인** | `RecoveryItemManager`의 `dropJumpHeight`(1.2)·`dropLandOffsetX`(1.5)가 `mapProtectRecovPrefab` 스프라이트 크기(**약 86×86** 월드 유닛) 대비 **너무 작음**. Y 변화 1.2·가로 1.5는 스프라이트의 **1~2%** 수준이라 1초 동안 움직여도 눈에 안 보임. |
| **검증** | 아크 디버그 로그 추가 후: `아크 시작` → `아크 정점`(peakY = start.y + jumpHeight) → `아크 착지 완료` 순서 확인 → **코루틴은 정상**, 수치만 문제. |
| **해결** | `GameScene` `RecoveryItemManager` Inspector에서 `dropJumpHeight`·`dropLandOffsetX`를 스프라이트 스케일에 맞게 상향 (예: jump 60~240, land 80~160). `dropDuration` 0.4~0.6s 권장. |
| **파일** | `RecoveryItemManager.cs`, `RecoveryItem.cs`, `GameScene.unity` |

---

## 2. 드랍 아이템 Y가 너무 낮음 (땅에 묻힘)

| 항목 | 내용 |
|------|------|
| **증상** | 아크는 보이나 회복 아이템 스프라이트 하단이 바닥·오염원 피벗에 묻혀 보임. |
| **원인** | 드랍 시작 위치가 오염원 `transform.position` 그대로. 맵 프리팹 피벗이 중심인데 오염원 Y가 지면 기준이라 아이템 절반이 아래로 내려감. |
| **해결** | `RecoveryItemManager.dropYOffset` 추가 — `spawnPos.y = pollutantPosition.y + dropYOffset`. 드랍·착지·아크 기준선 모두 동일 오프셋 적용. |
| **기본값** | 코드·씬 **30** (스테이지·스프라이트에 맞게 Inspector 조절). |
| **파일** | `RecoveryItemManager.cs`, `GameScene.unity` |

---

## 3. 아크 디버그 로그 추가

| 항목 | 내용 |
|------|------|
| **목적** | 드랍 vs 아크 vs 픽업 단계를 Console에서 구분. |
| **로그** | `[RecoveryItem] 아크 시작` (시작·착지·jumpHeight·duration) · `아크 정점` (t≥0.5, 1회) · `아크 착지 완료` (픽업 콜라이더 ON) · `duration<=0` 시 `아크 생략` |
| **파일** | `RecoveryItem.cs` |

**정상 순서 예:**

```text
[RecoveryItemManager] 드랍: ...
[RecoveryItem] 아크 시작 — ...
[RecoveryItem] 아크 정점 — pos=..., peakY=...
[RecoveryItem] 아크 착지 완료 — pos=..., 픽업 콜라이더=ON
[RecoveryItem] 획득: id=...
```

## 4. `RecoveryItem` 부착 위치 (참고)

| 오브젝트 | `RecoveryItem` |
|----------|----------------|
| `mapProtectRecovPrefab` | ✅ |
| `mapTimeRecovPrefab` | ✅ |
| `inv*RecovPrefab` (인벤 UI) | ❌ |
| `GameScene` Hierarchy 직접 배치 | ❌ (런타임 `Instantiate`만) |

드랍 경로: `Pollutant` HP 0 → `FadeOutAndDestroy` → `RecoveryItemManager.TryDropOnPollutantCleared` → `StartDropArc`.

맵 고정 스폰(`RecoveryItemSpawner`)은 **폐기** — 아크 드랍만 사용 ([0610 Bug §7](2026-06-10-오후1430-0610-일일-오후2030-2차-fixes.md)).

## 5. Inspector 권장 (`RecoveryItemManager`)

| 필드 | 용도 | 비고 |
|------|------|------|
| `dropYOffset` | 드랍·착지 Y 보정 | 땅에 묻히면 올림 |
| `dropJumpHeight` | 아크 최대 높이 | 스프라이트 높이(~86)의 0.5~3배 참고 |
| `dropLandOffsetX` | 좌/우 착지 거리 | 랜덤 부호 |
| `dropDuration` | 아크 시간(초) | 0.4~0.6 |
| `testAlwaysDrop` | 확률 무시 100% 드랍 | **빌드 전 OFF** |

## 6. Play 테스트 체크리스트

- [ ] 오염원 정화 후 `[RecoveryItemManager] 드랍:` 로그
- [ ] `[RecoveryItem] 아크 시작` → `정점` → `착지 완료` 순서
- [ ] Scene 뷰에서 아이템이 위로 튀었다 좌/우로 착지
- [ ] 아이템이 땅에 과도하게 묻히지 않음 (`dropYOffset` 조절)
- [ ] 착지 후 플레이어 접촉 → 인벤 획득
- [ ] `testAlwaysDrop` 빌드 전 해제

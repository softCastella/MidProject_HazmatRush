맵에서 회복 아이템 획득 후 인벤에 이름·이미지·Count가 보이지 않거나, 레이아웃·비율이 어긋나는 문제 보고·수정 기록입니다.

---

## 1. 아이템 획득 후 인벤 Name/Image/Count가 비활성 유지

| 항목 | 내용 |
|------|------|
| **증상** | 맵에서 회복 아이템을 줍아도 인벤 칸에 이름·아이콘이 안 보임. `invEmptySlotPrefab`의 Name/Image/Count가 계속 비활성. |
| **원인** | 빈 칸 프리팹은 **의도적으로** Name/Image/Count를 끈 상태. 아이템 표시는 칸 안에 `invProtectRecovPrefab` / `invTimeRecovPrefab`을 **`InvItemView`** 로 Instantiate해야 함. 초기 구현은 루트 RectTransform만 (0,0)으로 맞추고 **자식 Image/Name 활성화·위치 보정 없음**. |
| **해결** | `RecoveryItemInventoryUI.UpdateInvItemView` — 획득 시 `InvItemView` Instantiate 후 `ApplyInvItemViewLayout`에서 Image/Name `SetActive(true)`, JSON `displayName` 텍스트 설정. Count는 **슬롯 루트** `Count` 자식에 숫자 표시(기존 `Refresh` 로직). |
| **파일** | `RecoveryItemInventoryUI.cs` |

---

## 2. InvItemView가 Viewport 밖 — 아이콘·이름이 안 보임

| 항목 | 내용 |
|------|------|
| **증상** | Console에 획득 로그는 나오나 UI에는 빈 칸만 보임. |
| **원인** | `invProtectRecovPrefab` / `invTimeRecovPrefab` 자식 Image·Name의 `anchoredPosition`이 **(457, -431)** 등 칸 크기(100×100) 밖 좌표로 저장됨(캔버스 전체 기준으로 제작된 값). 루트만 0,0이면 자식이 마스크 밖으로 나감. |
| **해결** | Instantiate 후 `ApplyInvItemViewLayout`에서 Image/Name 위치·크기를 **빈 칸 프리팹 기준**으로 코드에서 재설정. `InvItemView` 루트는 stretch (0,0)~(1,1)로 칸 전체 채움. |
| **파일** | `RecoveryItemInventoryUI.cs` |
| **프리팹** | YAML 직접 수정 없음 — 런타임 보정(프리팹 임의 변경 지양) |

---

## 3. 아이콘 비율 찌그러짐 · 레이아웃이 아래로 밀림

| 항목 | 내용 |
|------|------|
| **증상** | 아이콘이 가로로 늘거나 작게 보임. 이름 텍스트가 칸 하단에 붙어 전체가 아래로 내려간 느낌. |
| **원인** | 인벤 아이템 프리팹 Image에 **비균등 `localScale` (1.8, 1.5)** · 작은 `sizeDelta` · `preserveAspect = false`. Name은 `lineSpacing -30`, 위치가 빈 칸(`y: -31.7`)과 불일치(`-30` 등). |
| **해결** | `ApplyInvItemViewLayout` — Image: 위치 `(0, 12.4)`, 크기 `44×44`, `preserveAspect = true`, 회전·스케일 1로 초기화. Name: 위치 `(0, -31.7)`, 크기 `80×30`, `displayName` 공백→`\n` 2줄, `lineSpacing = 0`. |
| **기준** | `invEmptySlotPrefab` 자식 Image/Name RectTransform 좌표 |
| **파일** | `RecoveryItemInventoryUI.cs` |

## 4. JSON 미연결 시 획득 자체가 실패할 수 있음

| 항목 | 내용 |
|------|------|
| **증상** | `recoveryItemsJson` 미할당·파싱 실패 시 `Add(id)`가 거부되어 픽업이 안 됨. |
| **원인** | 초기 `Add(int)`가 `GetItemDef(itemId) == null`이면 `return false`. |
| **해결** | `EnsureFallbackDefs()` — JSON 없을 때 id 1·2 기본 정의(방호복 회복제 / 시간 연장기). `Add`는 id>0이면 획득 진행, 정의 없을 때만 경고 로그. |
| **파일** | `RecoveryItemInventory.cs` |

## 5. 회복 인벤 로직·UI 1차 구현 (참고)

| 항목 | 내용 |

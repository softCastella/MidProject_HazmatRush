Unity CLI — youngwoocho02/unity-cli

이 프로젝트는 MCP가 아닌 unity-cli 로 에디터를 제어합니다.

두 가지를 구분

이름역할
unity-cli.exePC에 설치된 CLI (터미널·Cursor가 실행)
unity-connectorUnity 패키지 — 에디터가 켜지면 HTTP(예: 8090) 로 대기
Tools/unity.ps1별도 — Unity.exe batchmode 빌드용 (연결과 무관)

CLI 설치됨: C:\Users\user\AppData\Local\unity-cli\unity-cli.exe

Unity Console에 포트가 안 보일 때

정상입니다. Connector는 Console에 포트 숫자를 출력하지 않고 아래 한 줄만 남깁니다.

[UnityCliConnector] HTTP server started

포트는 기본 8090이고, 이미 쓰 중이면 8091~8099를 순서대로 시도합니다. 확인 방법:

cd C:\Users\user\Documents\Workspace\MidProject
unity-cli status

예: Unity (port 8090): ready

또는 %USERPROFILE%\.unity-cli\instances\*.json 안의 "port":8090

지금 연결이 안 보일 때 (체크리스트)

  1. MidProject를 Unity Hub에서 연다 (다른 프로젝트만 열려 있으면 8090이 다른 경로일 수 있음)
  2. Packages/manifest.json에 com.youngwoocho02.unity-cli-connector 있는지 확인 → 없으면 Package Manager에서 git URL 추가
  3. 패키지 import 후 Console에 Connector 관련 로그 없는지 확인
  4. PowerShell에서 프로젝트 폴더로 이동 후: 
    cd C:\Users\user\Documents\Workspace\MidProject
unity-cli status
    Unity: ready 와 포트(예: 8090)가 나오면 성공
  5. Cursor는 터미널에서 unity-cli console 등을 실행해 로그를 가져옴 (Unity Console UI “연결” 표시와는 별개)
예전에 본 8090은 다른 프로젝트(SpaceShooter) 인스턴스일 수 있습니다. MidProject를 연 상태에서 unity-cli status로 포트를 다시 확인하세요. 인스턴스 정보: %USERPROFILE%\.unity-cli\instances\*.json

Unity 패키지 (git URL)

자주 쓰는 명령

unity-cli status
unity-cli console --type error,warning,log --lines 30
unity-cli editor play --wait
unity-cli editor stop

권장 설정

Unity Edit → Preferences → General → Interaction Mode → No Throttling (백그라운드에서 CLI 응답 지연 줄이기)

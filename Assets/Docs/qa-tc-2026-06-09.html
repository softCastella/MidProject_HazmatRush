QA TC — MidProject

QA팀 배포용 Test Case · 대상: 경고 · 맵·회복 · 이동·접촉 (2026-06-09 기준) · Unity 6000.4.8f1 · 빌드 또는 에디터 Play

진행 방법
1) Unity에서 TitleScene 또는 GameScene 연 후 ▶ Play
2) 아래 시나리오 1 → 6 순서대로 플레이 (한 시나리오 = 한 장 분량)
3) 「정상 결과」가 눈에 보이면 ✓ · 아니면 Fail 칸에 간단히 적기
조작 키 (참고): 이동 ←→ · 중화 아이템 Z/X · 회복 C/V · 회복 사용 Space

시나리오 1 — 게임 시작 · 가이드 · 첫 이동 구간

목적: 튜토리얼 후 짧은 구간만 걸을 수 있고, 오염원 등장 전후로 이동 범위가 바뀌는지 확인.

✓#단계시나리오정상 결과 (화면)Fail 시
1-1게임 진입 Title에서 Start → 로딩 후 GameScene (또는 GameScene에서 바로 Play) 플레이어·UI·타이머·배경이 보임 검은 화면·멈춤
1-2가이드 중 시작 안내 문구가 나온 동안 ←→ 입력 캐릭터가 움직이지 않음 가이드 중 이동됨
1-3가이드 후 안내가 끝난 뒤 좌우 이동 이동 가능 · 타이머 감소 · 배경이 함께 흐름 이동·타이머·배경 중 하나라도 안 됨
1-41차 구간 한계 오른쪽 끝까지 이동 (아직 오염원 없을 때) 일정 지점에서 더 이상 오른쪽으로 못 감 (짧은 구간) 끝없이 오른쪽으로만 감
1-5멈춘 상태 1-4 한계 근처에서 키를 뗀 채 2~3초 대기 캐릭터 위치가 저절로 튀거나 끌려가지 않음 가만히 있는데 위치가 밀림

시나리오 2 — 오염원 경고 · 등장 연출

목적: 경고 때 “게임 전체가 멈춘 것처럼” 보이지 않고, 필요한 것만 멈추는지 확인.

✓#단계시나리오정상 결과 (화면)Fail 시
2-1경고 발생 가이드 후 오른쪽으로 2~3초 계속 이동 경고 문구·깜빡임 표시 경고 없음
2-2경고 중 멈춤 경고가 뜬 뒤 ←→ · Z/X · C/V · Space · K/I 입력 시도
  • 캐릭터·배경·타이머가 멈춘 것처럼 보임
  • 위 키 입력에 반응 없음
 이동·타이머·아이템 조작됨
2-3경고 중 유지 경고 연출 중 BGM·경고 깜빡임·아이템 안내 관찰 BGM은 계속 들림 · 경고·안내 연출은 진행 BGM까지 끊기거나 화면 전체 일시정지
2-4오염원 등장 연출이 끝날 때까지 대기 오염원이 페이드인 · 이후 이동·타이머·Z/X 다시 가능 오염원 없음 · 영구 잠금
2-5이동 확장 오염원 등장 후 다시 오른쪽 끝까지 이동 경고 전보다 더 오른쪽까지 갈 수 있음 여전히 짧은 구간에서 막힘

시나리오 3 — 오염원 접촉 · 중화

목적: 닿은 채로 움직여도 접촉이 끊기지 않고, 맞는/틀린 도구가 화면에 맞게 동작하는지 확인.

✓#단계시나리오정상 결과 (화면)Fail 시
3-1접촉 시작 오염원에 닿기 방호복 HP·오염원 HP바 표시 바 없음
3-2접촉 중 이동 닿은 채로 좌우로 계속 이동 (5초 이상) 방호복 HP가 계속 줄어듦 · HP바가 사라지지 않음 중간에 접촉 끊김·HP바 사라짐
3-3틀린 도구 Z/X로 오염원에 맞지 않는 도구 선택 후 접촉 방호복만 감소 · 오염원 HP 안 줄어듦 · 중화 이펙트 없음 오염원 HP 감소 또는 이펙트
3-4맞는 도구 Z로 해당 오염원용 중화제 선택 후 접촉 방호복 감소 + 오염원 HP 감소 + 중화 이펙트 HP 안 줄거나 이펙트 없음
3-5떨어짐 중화 중 오염원에서 일부러 떨어지기 오염원 HP바 사라짐 · 다시 닿으면 HP가 처음부터 떨어져도 HP 유지
3-6제거 후 아이템 오염원 HP를 0까지 깎은 뒤 Z/X로 다른 도구 선택 선택한 중화 아이템이 그대로 유지 (강제로 스캐너 등으로 안 바뀜) 제거 직후 아이템 리셋

시나리오 4 — 회복 아이템 (맵 드랍)

목적: 오염원 제거 후 회복 아이템이 떨어지고, 맵에 남아 있을 때 배경·픽업이 자연스러운지 확인.

✓#단계시나리오정상 결과 (화면)Fail 시
4-1드랍 오염원을 중화해 제거 (회복 드랍 있는 경우) 회복 아이템이 포물선으로 떨어져 맵에 놓임 드랍 없음·바닥 관통
4-2배경 정지 아이템이 맵에 남아 있는 동안 ←→ 이동 배경 스크롤이 멈춘 상태 아이템 있는데 배경만 계속 흐름
4-3픽업 캐릭터를 아이템에 가까이 이동 인벤에 아이콘·이름·개수 표시 · 맵에서 아이템 사라짐 인벤 안 들어감
4-4픽업 후 배경 맵에 아이템이 없어진 뒤 이동 배경 스크롤이 다시 정상적으로 움직임 줍었는데도 배경 안 움직임

시나리오 5 — 맵 구간 클리어 · 다음 구역

목적: 한 구역의 오염원을 다 없앤 뒤, 안내에 따라 이동해야 다음 맵으로 넘어가는지 확인.

✓#단계시나리오정상 결과 (화면)Fail 시
5-1구역 클리어 현재 맵의 A·B·C 오염원을 모두 제거 즉시 화면 페이드 없음 · 「오른쪽으로 이동하세요」류 안내 표시 클리어 직후 바로 페이드·맵 전환
5-2회복 남김 회복 아이템을 맵에 안 줍고 오른쪽 끝까지 이동 맵 끝까지 갈 수 있음 (줍지 않아도 진행 가능) 아이템 때문에 진행 불가
5-3맵 전환 안내대로 맵 오른쪽 끝까지 이동 페이드 후 다음 구역 · 새 배경·새 오염원 준비 끝까지 가도 전환 안 됨
5-4다음 구역 플레이 전환 후 가이드·이동·경고·오염원 흐름 재확인 다시 짧은 구간 → 경고 → 오염원 → 이동 확장 패턴 반복 이동·배경·타이머 꼬임

시나리오 6 — 스테이지 클리어 · 사망

목적: 스테이지를 깼을 때·죽었을 때 결과 화면 연출 순서 확인.

✓#단계시나리오정상 결과 (화면)Fail 시
6-1클리어 · 회복 맵에 회복 아이템을 남긴 채 스테이지 최종 클리어 클리어 전에 인벤 개수 증가 · 맵 아이템 사라짐 남긴 아이템 유실
6-2클리어 연출 클리어 순간부터 관찰 클리어 동작 재생 → 잠시 후 동작 정지 → 그 다음 클리어 결과 패널 동작과 패널이 동시에 뜸
6-3사망 연출 (별도 플레이) 방호복 HP를 0까지 깎기 사망 동작 → 잠시 후 → 게임오버 패널 (클리어와 같은 템포) 패널이 너무 빨리 또는 동시
6-4가스 오염원 (가능하면) 가스(D) 오염원 접촉 · 맞는 도구로 처리 밸브 연출·SFX · 중화 이펙트는 없음 · 접촉·데미지는 일반과 같음 가스만 접촉 안 됨·이펙트 이상

시나리오 7 — 이동·배경 체감 (선택)

목적: 플레이어와 배경 속도가 어색하지 않은지 주관 확인. Fail 기준이 애매하면 메모만 남기면 됨.

✓#단계시나리오정상 결과 (화면)Fail 시
7-1속도 비율 가이드 후 오른쪽으로 5초 이상 이동 배경이 플레이어와 함께 자연스럽게 지나감 (배경만 미친 듯 빠르지 않음) 배경만 너무 빠름/느림
7-2방향 전환 ←→ 를 빠르게 번갈아 입력 이동 가능 (체감 메모: 가속·끊김 느낌 있으면 적기) 입력 불가·심한 끊김
